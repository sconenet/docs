# CLI (`scone`) — লগিং ও ভার্বোসিটি

> `scone` বাইনারির লগিংয়ের নরমেটিভ আচরণ। ডক/কোডের যেকোনো
> বৈপরীত্য = বাগ (সত্যের উৎস সংশোধন করুন)।

## নীতিমালা

- **stdout কমান্ড আউটপুটের জন্য সংরক্ষিত** (`scone status`,
  `identity list`, `status`, …)। একটি স্ক্রিপ্ট stdout রিডাইরেক্ট
  করতে পারে এবং এতে কখনো লগ খুঁজে পাবে না — পাইপিং নির্ভরযোগ্য থাকে।
  গৃহীত ব্যতিক্রম: `scone relay` ডেটা লাইনগুলো
  `p2p: <multiaddr>`, `dns: <addr>`, এবং `metrics: <addr>` stdout-এ
  নির্গত করে যত তাড়াতাড়ি লিসেনারগুলো বাইন্ড হয়
  (`--bootstrap` / কনফিগারেশনের জন্য ব্যবহারযোগ্য ডেটা, লগ নয়;
  প্রতিটি ঠিক একবার নির্গত, অবিলম্বে ফ্লাশ করা)।
- **সব লগ stderr-এ যায়** (কমপ্যাক্ট `tracing` ফরম্যাট), রিলের
  লগসহ — মাইগ্রেশনের আগেও রিলে stderr-এ লগ করত।
- CLI-র ব্যবহারকারীমুখী ত্রুটি বার্তা (`scone: <error>`) stderr-এ
  থাকে: এটি UX, লগ নয়।

## স্তর এবং `--verbose` / `-v`

| ইনভোকেশন | কার্যকর স্তর |
|---|---|
| `scone <cmd>` (`-v` ছাড়া) | `warn` |
| `scone relay` (`-v` ছাড়া) | `info` |
| `scone -v <cmd>` / `scone relay -v` | `info` |
| `scone -vv …` | `debug` |
| `scone -vvv …` (এবং আরও) | `trace` |

`-v`/`--verbose` একটি **গ্লোবাল ও পুনরাবৃত্তিযোগ্য** ফ্ল্যাগ: এটি
সাবকমান্ডের আগে বা পরে গৃহীত হয় (`scone -vv identity list`
এবং `scone identity list -vv` সমতুল্য)।

**কেন `scone relay` ডিফল্টে INFO-তে থাকে**: রিলে একটি
ডেমন — পরিচালনাযোগ্য হতে এটিকে নিজের কার্যকলাপ লগ করতে হবে
(RPC/p2p লিসেনিং, গৃহীত ও উৎপাদিত ব্লক, সংযুক্ত পিয়ার, প্রত্যাখ্যান),
 কোনো ফ্ল্যাগ ছাড়াই। অন্যদিকে ওয়ান-শট কমান্ডগুলো নীরব থাকে
(WARN) যাতে টার্মিনাল বা স্ক্রিপ্ট দূষিত না হয়।

## `RUST_LOG` (ওভাররাইড)

`RUST_LOG` এনভায়রনমেন্ট ভেরিয়েবল সেট থাকলে এটি `-v` থেকে
ডেরিভড স্তরকে **সম্পূর্ণ প্রতিস্থাপন** করে (`env-filter` সিনট্যাক্স):

```bash
RUST_LOG=debug scone identity list        # debug without -v
RUST_LOG=error scone -vv relay            # error wins over -vv
RUST_LOG=scone_network=trace,info scone relay   # per-target
```

## এনভায়রনমেন্ট কনফিগারেশন (`.env`)

আর্গুমেন্ট পার্স করার আগে, `scone` বর্তমান ডিরেক্টরি থেকে একটি
`.env` ফাইল লোড করে (`main.rs`-এ `dotenvy::dotenv()`)। ফাইল
অনুপস্থিত = নীরব নো-অপ, কখনো ত্রুটি নয়। লোড করা মানগুলো যেসব
রিলে অপশন একটি এনভায়রনমেন্ট ভেরিয়েবল ঘোষণা করে
(`cli.rs`-এ `env = "…"`) তাদের বেজলাইন হয়ে যায়।

অগ্রাধিকার (একটি অপশন, তিনটি উৎস):

```text
explicit CLI flag  >  .env variable  >  built-in default
```

- কমান্ড লাইনে পাস করা ফ্ল্যাগ সর্বদা জেতে;
- নয়তো ভেরিয়েবল (`.env` থেকে লোড বা আসল প্রসেস
  এনভায়রনমেন্টে সেট — একই ভেরিয়েবল, একই প্রভাব);
- নয়তো clap-এর বিল্ট-ইন ডিফল্ট।

পুনরাবৃত্তিযোগ্য ভেরিয়েবল (`SCONE_BOOTSTRAP`, `SCONE_DNS_UPSTREAM`)
জমা হয়: `.env`-এ প্রতি মানে একটি লাইন (dotenvy অ্যাপেন্ড করে)।

`SCONE_*` ভেরিয়েবলের সম্পূর্ণ টেবিল (নেটওয়ার্ক, P2P লিসেন,
বুটস্ট্র্যাপ, জেনেসিস, mDNS, UPnP, DNS সারফেস, মেট্রিক্স, টোপোলজি
প্রোফাইল, অ্যাঙ্কর) এবং প্রতিটির শব্দার্থ
[`relay.md`](relay.md#environment-configuration-env)-এ;
কমেন্টেড টেমপ্লেট রিপোজিটরি রুটে `.env.example` (`.env`-এ
কপি করুন, কখনো কমিট করবেন না — `.env` gitignored)।

## স্তরের শব্দার্থ (কোড রীতি)

- `error!`: ব্যর্থতা (আজ কোনো কল সাইট নেই — নেটওয়ার্ক ব্যর্থতা
  `warn!` হিসেবে গিলে ফেলা হয় এবং শুধুমাত্র মারাত্মক লোকাল
  ব্যর্থতা `run()` থেকে টাইপড ত্রুটি হিসেবে পৃষ্ঠে ওঠে);
- `warn!`: প্রত্যাখ্যাত শত্রুভাবাপন্ন বা ক্ষতিকর নেটওয়ার্ক এন্ট্রি,
  মেমপুল থেকে বহিষ্কৃত পুরনো tx, উৎপাদনকালে বাদ দেওয়া
  সংঘর্ষপূর্ণ tx, আউটবাউন্ড/ইনবাউন্ড ব্যর্থতা, DHT কী অমিল;
- `info!`: ব্লক গৃহীত/উৎপাদিত, RPC/p2p লিসেনিং, পিয়ার
  সংযুক্ত, রিলে স্টার্টআপ (স্টেট চেকপয়েন্ট);
- `debug!`: অভ্যন্তরীণ বিবরণ (tx গৃহীত, পিয়ার বিচ্ছিন্ন, RPC
  রাউন্ড ট্রিপ, keystore লিস্টিং, `SCONE_KAD_DEBUG`-এর
  অধীনে kad ইভেন্ট);
- `trace!`: পেলোডের জন্য সংরক্ষিত (আজ কোনো কল সাইট নেই)।

লাইব্রেরি ক্রেট (`scone-network`, …) `tracing` ম্যাক্রো নির্গত করে
কিন্তু **কোনো সাবস্ক্রাইবার ইনিশিয়ালাইজ করে না**: ইনিশিয়ালাইজেশন
শুধুমাত্র `scone` বাইনারিতে থাকে (সাবকমান্ড ডিসপ্যাচের আগে —
রিলের বুট থেকেই তার লগ প্রয়োজন)।


## সহজ ব্যবহার (cli-simplify-v1)

- **কোনো `--peer` প্রয়োজন নেই**: কমান্ডগুলো ডিফল্টে লোকাল
  রিলের সাথে কথা বলে; `SCONE_PEER` env বা `--peer` ওভাররাইড করে।
- **কোনো `--identity` প্রয়োজন নেই** যখন কীস্টোরে একটি একক
  পরিচয় থাকে (নীরবে ব্যবহৃত হয়; একাধিক হলে → ত্রুটি সেগুলো
  তালিকাভুক্ত করে)।
- অপসারিত (স্টাব বিকল্প সাজেস্ট করে): `show`, `submit`,
  `lookup`, `owned`।
- নতুন: `scone domain renew <name>`, `scone domains`, `scone domain
  get|set` (একক রেকর্ড, কোনো ফাইল নয়)।

```bash
scone identity generate me
scone domain register example.scone
scone domain set example.scone A 192.0.2.1
scone domain renew example.scone
```

## TLD জীবনচক্র (cli-unified-lifecycle)

`scone tld register <tld>` হলো এক-কমান্ড TLD এন্ট্রি পয়েন্ট,
`scone domain register`-এর সাথে প্রতিসম — অন-চেইন অবস্থা
আগে পড়া হয়, তারপর সঠিক ক্রিয়া চলে:

- **মুক্ত TLD** → নিবন্ধিত, **ডিফল্টে ওপেন জন্ম** (কোনো ফ্ল্যাগ
  নেই: স্ব-সেবা নেমস্পেস, PoW-র ১/৩)। `--private` সম্পূর্ণ PoW
  মূল্যে একটি মালিকানাধীন নেমস্পেস বেছে নেয়, একটি স্পষ্ট
  নিশ্চয়তার সাথে (অর্থনৈতিক সিদ্ধান্ত)। `--yes` নিশ্চয়তা এড়িয়ে
  যায় (স্ক্রিপ্ট)।
- **আপনার, ৯০ দিনের মধ্যে মেয়াদোত্তীর্ণ** → নবায়ন (RENEWAL)
  প্রস্তাবিত হয় (বর্তমান মেয়াদের সাথে আবদ্ধ PoW — অ্যান্টি-রিইউজ)
  এবং নিশ্চয়তার পরে চালায়।
- **আপনার, মেয়াদ থেকে দূরে** → কিছু করার নেই (`tld renew --force`
  যেকোনোভাবে নবায়নের জন্য)।
- **অন্য কারো** → owner-সহ পরিষ্কার টাইপড ত্রুটি।

```bash
scone tld register mytld            # open birth (default)
scone tld register mytld --private  # owned namespace (confirm)
scone tld renew mytld               # explicit renewal
```

একইভাবে, আপনার মালিকানাধীন একটি নামে `scone domain register <name>`
যা ৯০ দিনের মধ্যে মেয়াদোত্তীর্ণ হয় ব্যর্থ হওয়ার বদলে নবায়ন
প্রস্তাব করে।

## অ্যাডভান্সড কমান্ড

উপরের ডিফল্টগুলো দৈনন্দিন ব্যবহার কভার করে। স্ক্রিপ্ট এবং
web/API ইন্টারঅপের জন্য সম্পূর্ণ সারফেস উপলব্ধ থাকে:

- `scone show <name>` — একটি নামের অভ্যন্তরীণ DomainId।
- `scone lookup <name>` / `scone owned <pubkey>` — `domain get` /
  `domains --pubkey`-এর উপনাম (একই আউটপুট)।
- `scone renew <name>` — `scone domain renew`-এর উপনাম।
- `scone domain info` — `scone domain get`-এর উপনাম।

অফলাইন হেক্স সারফেস (`tx build|sign|verify`, `submit tx`
সাবকমান্ড) অপসারিত হয়েছে (remove-tx-surface-v2): যে M8b
অপারেশনগুলোর সেবা দিতো সেগুলো এখন ফার্স্ট-ক্লাস কমান্ড —
`scone tld open <tld>` (একমুখী স্ব-সেবা উন্মুক্তকরণ, উন্মুক্তকরণের
PoW আপনার জন্য মাইনড), `scone tld transfer <tld> <owner>`,
`scone tld revoke <tld>`, `scone domain assign <name> <owner>`
(TLD owner, প্রাইভেট TLD) এবং `scone domain transfer <name>
<owner>`। প্রতিটি: স্টেট রিড, সিগনেচার, সাবমিশন, txid। DNS
রেকর্ড রেজোলিউশন `scone domain resolve <name>`-এ স্থানান্তরিত
(পূর্বের `record get`); হেক্স পাবলিকেশন চ্যানেল (`record put`)
আর নেই — সম্পাদনা `domain set` / `domain update` দিয়ে যায়।
- `scone domain export <name> [--out FILE]` — চেইন-ভেরিফায়েড
  রেকর্ড সেট ঠিক `update --file` ফরম্যাটে লেখে
  (রাউন্ড-ট্রিপ নিশ্চয়তা: export → সম্পাদনা → update একই
  সেট পুনঃসাবমিট করে)। `--out` ছাড়া: stdout। `domain resolve`
  একই পাঠযোগ্য ফরম্যাট ব্যবহার করে, তাই `resolve > zone.txt`
  সরাসরি ইমপোর্টযোগ্য। যেসব কাইন্ডের কোনো টেক্সচুয়াল সিনট্যাক্স
  নেই (GEOROUTE, অজানা) সেগুলো কমেন্টেড সতর্কতা হিসেবে এক্সপোর্ট
  হয় — কখনো নীরবে বাদ দেওয়া হয় না।

`domain get` এছাড়াও `domain_id` এবং `valid_until` প্রিন্ট করে।

## বিল্ড: dev বনাম মেইননেট-সক্ষম (mainnet-compile-gate)

ডিফল্ট বিল্ডে **কোনো মেইননেট নেই**: `scone relay --network
mainnet` (এবং `SCONE_NETWORK=mainnet` সহ রেজিস্ট্রার সেবা)
একটি রিবিল্ড ইঙ্গিতসহ অবিলম্বে ব্যর্থ হয়। অফিসিয়াল বিতরণকৃত
বাইনারি দিয়ে তৈরি হয়:

```bash
cargo build --release --features mainnet
```

`scone --version` এমন বিল্ডে `+mainnet` দেখায়, এবং
রিলে স্টার্টআপ লগ বলে `build: mainnet-enabled`।

ডিফল্ট `--network`-ও বিল্ড অনুসরণ করে: মেইননেট-সক্ষম বিল্ডে
`mainnet` (অফিসিয়াল বাইনারি ব্যবহারকারীদের প্রোডাকশন
নেটওয়ার্কে নামায়), অন্যথায় `testnet`। একটি স্পষ্ট
`--network` ফ্ল্যাগ বা `SCONE_NETWORK` env সর্বদা জেতে
(clap ক্রম: ফ্ল্যাগ > env > ডিফল্ট)। এটি একটি
অপারেশনাল গার্ডরেল (দুর্ঘটনাকৃত রান, dev/CI বাইনারি) — কোনো
ক্রিপ্টোগ্রাফিক সীমানা নয়; কনসেনসাস নিয়মই শত্রু নোডের
বিরুদ্ধে প্রতিরক্ষা থাকে যায়।
