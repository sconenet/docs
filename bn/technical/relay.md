# নেটওয়ার্ক রিলে (M4) — স্থাপত্য, প্রবাহ এবং CLI নিয়ন্ত্রণ

> Scone নেটওয়ার্ক রিলের (`scone-network`) নরমেটিভ স্পেসিফিকেশন।
> ডক/কোডের যেকোনো বৈপরীত্য = বাগ (সত্যের উৎস সংশোধন করুন)।

## ওভারভিউ

**রিলে** হলো Scone-এর সম্পূর্ণ P2P নোড: এটি ক্যানোনিকাল
ব্লকচেইন বজায় রাখে (RAM + `NodeStore` redb), লেনদেন ও ব্লক
রিলে করে,
ব্লক উৎপাদন করে (devnet মোড), সিঙ্ক প্রোটোকল সেবা দেয়,
একটি Kademlia DHT-তে `SignedDnsRecord` প্রকাশ করে ও
রেজোলিউশন করে, এবং **p2p প্রোটোকল** (`/scone/reqres/1`)
উন্মুক্ত করে যা CLI সরাসরি কোয়েরি করে
(RPC→p2p একীকরণ: JSON TCP চ্যানেল চলে গেছে)।

```text
                    ┌────────────────────────────────────────┐
                    │              scone relay               │
  P2P (libp2p)      │                                        │
  QUIC (udp,        │  Swarm libp2p                          │
  ephemeral port    │  ├─ identify  (address discovery)      │
  by default) ◄─────┤  ├─ ping      (liveness)               │
                    │  ├─ kad       (record DHT)             │
                    │  └─ reqres    (scone-prot. messages)   │
                    │                                        │
                    │  Relay core (single task)              │
                    │  ├─ Blockchain (full validation)       │
                    │  ├─ Mempool (bounded, dedup by TxId)   │
                    │  ├─ BlockBuilder (devnet production)   │
                    │  ├─ Fork parking (bounded, 2048)       │
                    │  └─ Sync driver (batched catch-up)     │
                    │                                        │
  CLI ◄─────────────┤  reqres p2p (QUIC, same messages)      │
                    └────────────────┬───────────────────────┘
                                     │
                              NodeStore (redb)
```

`crates/scone-network` হলো ওয়ার্কস্পেসের **একমাত্র অ্যাসিঙ্ক ক্রেট**:
এর নিচের সবকিছু (crypto → core → protocol → blockchain →
storage) সিঙ্ক্রোনাস ও বিশুদ্ধ থাকে।

## সংযোগ ভর্তি (P1.5)

স্ওয়ার্ম স্তরে কঠোর সীমা (libp2p `connection_limits` আচরণ,
`SconeBehaviour`-এর প্রথম এন্ট্রি):

- `MAX_TOTAL_CONNECTIONS = 128` — প্রতি রিলেতে প্রতিষ্ঠিত
  সংযোগের (ইনকামিং + আউটগোয়িং) ক্যাপ; অতিরিক্ত ইনকামিং
  REFUSED, কখনো সারিবদ্ধ নয়;
- `MAX_PER_PEER_CONNECTIONS = 4` — একটি একক পিয়ার অনেক
  সংযোগ খুলে মোট কোটা একচেটিয়া করতে
  পারে না;
- `MAX_PENDING_INCOMING = 32` — slowloris গার্ড:
  অপ্রমাণীকৃত হাফ-সংযোগ কখনো অনির্দিষ্টকাল
  অপেক্ষা করে না।

এই সীমাগুলো বিদ্যমান প্রতি-বার্তা সীমা
(`MAX_MESSAGE_LEN` 1 MiB) এবং প্রতি-বাজেট সীমার (সিঙ্ক
`max ≤ 128` ব্লক, DNS TCP 64 সংযোগ/512 B/5 সে) পরিপূরক। একটি
সংযোগ-বন্যার আক্রমণকারী প্রত্যাখ্যান পায়, মেমরি বৃদ্ধি নয়।

## পিয়ার ডিসকভারি

তিনটি পরিপূরক প্রক্রিয়া, এই অগ্রাধিকার ক্রমে:

1. **স্পষ্ট সিড** (`--bootstrap`, সম্পূর্ণ multiaddr) — সর্বদা
   অগ্রাধিকার নেয়; একটি অ-খালি তালিকা দিলে বাকি সবকিছু
   প্রতিস্থাপিত হয়।
   `--no-builtin-seeds` ১০০% প্রাইভেট
   স্থাপনার জন্য এমবেডেড সিড খালি করে।
2. **এমবেডেড সিড** (`builtin_seeds(network)`
   `scone-network/src/config.rs`-এ) — প্রতিটি অফিসিয়াল বাইনারি
   রিলিজে ফ্রোজেন, প্রতি নেটওয়ার্কে। একটি অ-কনফিগারকৃত রিলে
   একা নেটওয়ার্কে যোগ দেয়। (পাবলিক টেস্টনেট স্থাপন
   না হওয়া পর্যন্ত টেস্টনেটে খালি।)
3. **শেখা ডিরেক্টরি** (`<data-dir>/peers.json`) — `identify`-এর
   মাধ্যমে শেখা প্রতিটি ঠিকানা ধরে রাখা হয় (শেষ দেখা; **২০০০
   এন্ট্রির** ক্যাপ — ঠিকানা, সংযোগ নয়, সর্বোচ্চে ~৪০০ KiB RAM
   — এবং একটি **৯০-দিনের বয়স কাটঅফ**: ৯০ দিনের বেশি আগে
   শেষ দেখা একটি এন্ট্রি রাইট টাইমে বাদ দেওয়া হয় এবং লোড
   টাইমে উপেক্ষিত, ২০০০ স্লট প্রাক-চার্ন জীবাশ্মের বদলে
   বিশ্বাসযোগ্য পিয়ারে পূর্ণ রেখে যাদের একমাত্র অবদান
   হতো একটি বুট-টাইম ডায়াল টাইমআউট) এবং প্রোডাকশন
   টিকে ~১×/মিনিটে সংরক্ষিত। কোনো সিড এবং কোনো বুটস্ট্র্যাপ
   ছাড়া বুটে, ডিরেক্টরি পুনর্গঠিত হয়: রিলে কোনো
   কনফিগারেশন ছাড়াই তার স্বাভাবিক পিয়ার খুঁজে পায়। এটি
   একটি ক্যাশ: অনুপস্থিত/দূষিত ফাইল = খালি
   ডিরেক্টরি, কখনো ত্রুটি নয়।
4. **UPnP** (`--upnp`, অপ্ট-ইন) — হোম
   রাউটার দ্বারা QUIC লিসেন-পোর্ট ম্যাপিং: নোড একটি
   সার্কিট রিলে **ছাড়াই** বাইরে থেকে পৌঁছানো যায়।
   `NewExternalAddr`-এ, বাহ্যিক
   ঠিকানা স্ওয়ার্মের প্রকৃত বাহ্যিক ঠিকানা হিসেবে নিবন্ধিত হয়
   (`add_external_address` — identify/autonat দ্বারা দেখা,
   একটি
   ট্রান্সপোর্ট-রিলে প্রার্থী)। কোনো IGD গেটওয়ে নেই
   (`GatewayNotFound`) বা অ-রাউটেবল গেটওয়ে
   (`NonRoutableGateway`): একটি সাধারণ ইনফো
   লগ, ম্যাপিং বাদ দেওয়া হয় — হোম LAN-এ স্বাভাবিক
   ক্ষেত্রে। একটি
   মেয়াদোত্তীর্ণ ম্যাপিং (ব্যর্থ নবায়ন) একটি সতর্কতা।

UPnP **ডিফল্টে নিষ্ক্রিয়** থাকে (`config.rs`-এ `enable_upnp` =
`false`): সম্মতি ছাড়া একটি পাবলিক স্থাপনা কোনো রাউটারের সাথে
কথা বলে না। **mDNS ডিসকভারি সরিয়ে ফেলা হয়েছে**
(remove-mdns-discovery, 2026-10-22): পিয়ারিং আসে কেবল স্পষ্ট
বুটস্ট্র্যাপ, বিল্ট-ইন সিড এবং Kademlia থেকে — লিগ্যাসি
`--mdns`/`SCONE_MDNS` ফ্ল্যাগ এখনও কোনো প্রভাব ছাড়াই গৃহীত হয়
(স্ক্রিপ্ট সামঞ্জস্য, `--rpc`-এর মতোই আচরণ)।

### লোকাল টোপোলজি অপ্টিমাইজেশন (সর্বদা চালু)

রিলে বিশুদ্ধ `scone-topology` ইঞ্জিন ব্যবহার করে তার
প্রতিবেশী সক্রিয়ভাবে অপ্টিমাইজ করে (ক্রেটের ডক দেখুন)।
**সর্বদা সক্ষম**;
একমাত্র উন্মুক্ত টিউনিং হলো একটি **প্রোফাইল**
(`--topology-profile`, env `SCONE_TOPOLOGY_PROFILE`,
ডিফল্ট `default`):

| প্রোফাইল | min / target / max | eval. | কার জন্য |
|---|---|---|---|
| `tiny` | 2 / 4 / 6 | 120 s | Raspberry Pi, হোম বক্স, 1-vCPU VPS |
| `small` | 4 / 8 / 12 | 90 s | ছোট সার্ভার, হোম NAS |
| `default` | 8 / 16 / 32 | 60 s | স্ট্যান্ডার্ড সার্ভার (ডিফল্ট) |
| `high` | 16 / 32 / 64 | 45 s | সার্বভৌম নোড, ব্যাকবোন |
| `very-high` | 32 / 64 / 128 | 30 s | ফাউন্ডার হাব |
| `devtest` | 2 / 4 / 6 | 5 s | **শুধুমাত্র ল্যাব/টেস্ট** (ডিজাইনে অস্থিতিশীল) |

```
scone relay --topology-profile tiny
```

সুরক্ষামূলক প্যারামিটার (হিস্টেরিসিস 0.15, কুলডাউন 600 s,
গ্রেস 120 s, পরিমাপ 15 s) সর্বত্র অভিন্ন: এগুলো
স্থিতিশীলতা রক্ষা করে এবং নোডের আকারের সাথে স্কেল করার
কারণ নেই। একটি অজানা নাম একটি টাইপড স্টার্টআপ ত্রুটি।

একটি অসামঞ্জস্যপূর্ণ কনফিগ (`min > target > max`,
`[0,1]`-এর বাইরের থ্রেশহোল্ড — `NaN` সহ —, শূন্য
ব্যবধান) একটি **টাইপড স্টার্টআপ ত্রুটি**, কখনো নীরব
আচরণ নয়।

**ভিউ (`TopologyView`)** — স্ওয়ার্ম ইভেন্ট দ্বারা খাওয়ানো:

- সফল `ping` → RTT পর্যবেক্ষণ (৮টি নমুনার মধ্যমা
  উইন্ডো);
- ব্যর্থ `ping` → নির্ভরযোগ্যতা শাস্তি;
- `identify` গৃহীত → ঠিকানা (≤ 4/পিয়ার) + ঘোষিত
  প্রোটোকল (kad/reqres/identify/relay বিটমাস্ক);
- সংযোগ প্রতিষ্ঠিত → সংযুক্ত অবস্থা, দিক
  (ইনকামিং/আউটগোয়িং), বয়স, সনাক্তকৃত সার্কিট-রিলে;
- সংযোগ বন্ধ → শাস্তি + চার্ন কাউন্টার শুধুমাত্র তখনই
  যদি অনিচ্ছাকৃত হয় (একটি স্বেচ্ছাসেবী
  বহিষ্করণ গণনায় আসে না);
- আউটগোয়িং ডায়াল ব্যর্থতা → নির্ভরযোগ্যতা শাস্তি।

ভিউ বাউন্ডেড (৫০০ পিয়ার; এর বাইরে, শুধুমাত্র
সংযুক্ত পিয়ার মুখস্থ থাকে)।

**kbuckets থেকে `kad_required`** — প্রতিটি মূল্যায়নের
আগে, রিলে Kademlia রাউটিং টেবিল হাঁটে: একটি পিয়ার
সুরক্ষিত যদি সে একটি বাকেটে `Connected` হয়, বা একটি
SATURATED বাকেটে `Disconnected` হয়
(k = 20)। একটি সুরক্ষিত পিয়ার কখনো
বহিষ্করণের জন্য বেছে নেওয়া হয় **না**।

**অপ্টিমাইজেশন লুপ** — প্রোফাইলের মূল্যায়ন
ব্যবধানে (`default`-এর অধীনে 60 s; উপরের টেবিল দেখুন):

1. `kad_required` পুনর্গণনা (kbuckets);
2. ইঞ্জিন মূল্যায়ন (হিস্টেরিসিস: ১২০ সে গ্রেস
   সময়কাল, +১৫% সর্বনিম্ন স্কোর
   উন্নতি, বহিষ্করণ কুলডাউন 600 s);
3. সিদ্ধান্ত প্রয়োগকৃত: `AddCandidate` → প্রার্থী
   ডায়াল; `Replace` → বহিষ্কৃত পিয়ার বন্ধ (একবার —
   প্রগতিশীল, কোনো লুপিং নয়) তারপর প্রতিস্থাপন
   ডায়াল;
4. একটি **মেট্রিক্স** স্ন্যাপশট লগ করা হয় (INFO
   স্তর): পরিচিত/সংযুক্ত/ইনকামিং/আউটগোয়িং/সার্কিট/সুরক্ষিত
   গণনা, গড়/মধ্যমা RTT, ভিন্ন IP বাকেট, সর্বোচ্চ
   ঘনত্ব, চার্ন (প্রতিস্থাপন/বিচ্ছিন্নতা)।

প্রতিবেশীর স্কোর কখনো একটি ট্রাস্ট মাপ নয়
(`scone-topology` ডক দেখুন): এর থেকে কোনো
কনসেনসাস সিদ্ধান্ত আসে না।

### রিচেবিলিটি (AutoNAT) এবং ট্রান্সপোর্ট রিলে (circuit-relay v2)

প্রতিটি রিলে AutoNAT চালায় (ক্লায়েন্ট + সার্ভার): নোড
তার পিয়ারদের এটিকে ফিরে ডায়াল করার
চেষ্টা করতে বলে; রায় (`reachable`: হ্যাঁ =
বাইরে থেকে পৌঁছানো যায়, না = NAT-এর পেছনে,
অজানা = এখনও পরীক্ষিত নয়) প্রতি ৫ মিনিটে রিফ্রেশ হয় এবং
`NodeStatus`-এ উন্মুক্ত (ফিল্ড
`nat_reachable`, ওয়্যার ভ্যারিন্ট 0/1/2) — CLI এটি প্রদর্শন
করে (`scone status`)। প্রাইভেট ঠিকানা গণনায়
আসে (`only_global_ips = false`): একটি LAN মেশ তার LAN
রিচেবিলিটি পরীক্ষা করে।

একটি পৌঁছানো যায় এমন রিলে circuit-relay v2 **hop**
সক্ষম করে (এটি NATed পিয়ারদের জন্য ট্রাফিক
রিলে করতে পারে) এবং **DCUtR** (হোল-পাঞ্চিং: একটি
সার্কিটের মাধ্যমে সংযুক্ত দুটি নোড একটি সরাসরি
সংযোগের চেষ্টা করে এবং রিলে
মুক্ত করে)। NATed বলে বিবেচিত একটি রিলে স্বয়ংক্রিয়ভাবে
প্রথম পরিচিত পৌঁছানো যায় এমন পিয়ার থেকে একটি
সংরক্ষণ চায় এবং এটির মাধ্যমে শোনে (ঠিকানা
`/p2p/<relay>/p2p-circuit`)।

প্রোডাকশন নিয়ম: একটি রিলেড NATed নোডের ব্লক
প্রোডিউসার হওয়া উচিত নয় (অবনমিত
লেটেন্সি/প্রাপ্যতা) — PoS নিয়ম (সিট = জীবিত
ডোমেইন) এখনও এটি নিষিদ্ধ করে না; পাবলিক টেস্টনেটের
আগে একটি অপারেশনাল প্রয়োজনীয়তা হিসেবে
ডকুমেন্ট করা হবে।

## ট্রান্সপোর্ট এবং libp2p প্রোটোকল

| প্রোটোকল | নাম | ভূমিকা |
|---|---|---|
| QUIC (quic-v1) | — | মূল ট্রান্সপোর্ট (udp) |
| identify | `/scone/id/1` | পিয়ার ঠিকানা ডিসকভারি (Kademlia টেবিল পূরণ করে) |
| ping | libp2p স্ট্যান্ডার্ড | লাইভনেস |
| Kademlia | `/scone/kad/1` | DHT: কী = `DomainId` (32 B), মান = `SignedDnsRecord`-এর ক্যানোনিকাল এনকোডিং |
| request-response | `/scone/reqres/1` | scone-protocol অ্যাপ্লিকেশন বার্তা |

### অ্যাপ্লিকেশন ফ্রেম (`/scone/reqres/1`)

প্রতিটি ফ্রেম হলো `len: u32 BE || bytes` যেখানে বাইটগুলো
হলো `scone-protocol`-এর একটি `Message`-এর
ক্যানোনিকাল এনকোডিং (বিদ্যমান
কোডেক — কোনো দ্বিতীয় ফরম্যাট নয়)। দৈর্ঘ্য
যেকোনো রিড বা অ্যালোকেশনের **আগে** `limits::MAX_MESSAGE_LEN`
দ্বারা সীমাবদ্ধ: একটি বড়
ফ্রেম ঘোষণা করা পিয়ার কোনো মেমরি খরচ ছাড়াই
প্রত্যাখ্যাত।

বিনিময়কৃত বার্তা (প্রতি রিকোয়েস্ট/রেসপন্স রাউন্ড-ট্রিপে
একটি):

| বার্তা | দিক | উত্তর |
|---|---|---|
| `Hello { version }` | হ্যান্ডশেক | `Hello` (লোকাল ভার্সন) |
| `Ping` / `Pong` | লাইভনেস | `Pong` |
| `GetBlock { hash }` | কোয়েরি | `Block` (RAM উইন্ডো) বা অজানা হলে `Pong` |
| `GetBlocks { start, max }` | সিঙ্ক | **একটি** `Block` (উচ্চতা `start`), বা না থাকলে `Pong` |
| `Block (b)` | ব্লক রিলে | `Pong` (ack) |
| `Transaction (tx)` | tx রিলে | `Pong` (ack) |
| `GetRecord { domain_id }` | লোকাল DHT | `Record` (লোকাল ক্যাশ) বা `Pong` |
| `Record (r)` | পাবলিকেশন | গৃহীত হলে `Pong`, অন্যথায় ত্রুটি |

নিয়ম: **প্রতি রিকোয়েস্টে ঠিক একটি উত্তর**;
স্বীকৃতি বার্তাগুলো হলো `Pong`। সিঙ্ক উত্তর একবারে একটি
ব্লক বহন করে — ক্যাচ-আপ
অনুরোধকারী পাশে ইটারেট করে ("সিঙ্ক" দেখুন)। এটি
সচেতনভাবে
বাউন্ডেড: প্রতি পিয়ারে একবারে একটির বেশি ব্লক
ইন-ফ্লাইট নয়।

## রিলে আচরণ

### স্টার্টআপ

0. নেটওয়ার্ক রেজোলিউশন (`--network testnet|mainnet|devnet`,
   প্রকল্প dev-এ থাকাকালীন ডিফল্ট testnet
   — M8b)। data-dir **প্রতি
   নেটওয়ার্কে** (`~/.scone/<network>/`): অন্য
   নেটওয়ার্কের চেইন ধারণকারী একটি অ-খালি স্টোর
   প্রত্যাখ্যাত (`Corrupted`);
1. redb স্টোর খুলুন/তৈরি করুন (`<data-dir>/chain.redb`);
2. `load_chain(store, network)`: O(1) টিপ + পেজিনেটেড
   ডোমেইন স্টেট
   (RAM উইন্ডো: জেনেসিস + টিপ);
3. স্ওয়ার্ম নির্মাণ (প্রতি-সেশন এফেমারাল Ed25519
   পরিচয় — নেটওয়ার্ক পরিচয় পারসিস্ট করা একটি
   খোলা সিদ্ধান্ত);
4. বুট তালিকা রচনা করুন ([পিয়ার
   ডিসকভারি](#পিয়ার-ডিসকভারি) দেখুন): স্পষ্ট
   `--bootstrap` (`/p2p/<peer-id>`-তে শেষ হতে হবে)
   ELSE নেটওয়ার্কের এমবেডেড
   সিড ELSE শেখা ডিরেক্টরি (`peers.json`);
5. প্রতিটি multiaddr ডায়াল করুন এবং Kademlia
   টেবিলে নিবন্ধন করুন
   (একটি মৃত ডায়াল উপেক্ষিত — বাকিরা নেটওয়ার্ক গঠন
   করে)।

### একটি লেনদেন গ্রহণ (P2P বা CLI জমা)

1. কঠোর বাউন্ডেড ডিকোডিং (`MAX_MESSAGE_LEN`);
2. সম্পূর্ণ ক্রিপ্টোগ্রাফিক ভ্যালিডেশন
   (`validate_transaction`: owner/কী বাঁধাই,
   ক্যানোনিকাল পেলোডের উপর `verify_strict`);
3. **অ্যান্টি-রিপ্লে আগে** (সস্তা, স্টেট-নিরপেক্ষ,
   চূড়ান্ত), তারপর স্টেট প্রি-চেক (`push_block` নিয়মের
   সস্তা আয়না — PoW, যা ব্যয়বহুল, শুধুমাত্র পুশ
   টাইমে যাচাই হয়): একটি
   রিপ্লেকৃত `RenewDomain` `TxReplay` উত্তর দেয়,
   একটি মিথ্যা PoW
   ত্রুটি নয় (এর প্রুফ সেই মেয়াদের সাথে বাঁধা
   যা প্রথম প্রয়োগ পার করেছে)। নেটওয়ার্ক
   পৃথকীকরণ ধাপ ২-এ প্রয়োগ হয়: সিগনেচার পেলোড
   রিলের নেটওয়ার্ক ইনজেক্ট করে, অন্যত্র স্বাক্ষরিত
   একটি tx `InvalidSignature` দিয়ে ব্যর্থ হয়
   (ওয়্যার 2026-09: আর কোনো `network` ফিল্ড নেই);
   `RegisterDomain` → নিবন্ধিত
   নামের TLD (অন্যথায় `UnknownTld`, D1/M7c)
   **এবং ওপেন** (অন্যথায়
   `TldClosed`, M8b) তারপর নাম মুক্ত; `UpdateDomain` →
   পরিচিত ডোমেইন, সঠিক সিকোয়েন্স `current + 1`,
   owner; `RegisterTld` → মুক্ত TLD;
   `TransferTld`/`RevokeTld`/`SetTldOpen` → পরিচিত
   TLD + owner স্বাক্ষরকারী; `AssignDomain` → TLD
   owner + মুক্ত নাম;
   `RenewTld` → পরিচিত প্রাইভেট TLD + owner, নির্দিষ্ট
   মেয়াদ পুনঃডেরিভড, গ্রেস-উইন্ডো প্রি-চেক;
   `RenewDomain` → পরিচিত ডোমেইন + owner, নবায়ন
   PoW প্রি-চেক (বর্তমান মেয়াদের
   সাথে আবদ্ধ) পরবর্তী উচ্চতায়;
4. মেমপুল সন্নিবেশ (নির্দিষ্ট ক্ষমতা, `TxId` দিয়ে
   ডিডুপ — পুলে থাকা একটি tx পুনঃজমা
   একটি নো-অপ);
5. পিয়ারদের কাছে সম্প্রচার (প্রেরক
   বাদে)।

### একটি ব্লক গ্রহণ (P2P, সিঙ্ক, বা স্ব-উৎপাদিত)

1. `push_block`: বিদ্যমান সম্পূর্ণ ভ্যালিডেশন (প্যারেন্ট
   = ক্যানোনিকাল টিপ, উচ্চতা, পুনর্গণনাকৃত মার্কেল রুট,
   প্রতিটি লেনদেন ভ্যালিডেট তারপর
   প্রয়োগকৃত — প্রতি ব্লকে অ্যাটমিক);
2. গৃহীত হলে: রিলে প্রয়োগের ফলাফল
   পড়ে (`push_block_with_gc` → হ্যাশ + ডিটারমিনিস্টিক
   GC দ্বারা সরানো ডোমেইন) এবং
   `store_block_with_removals` দিয়ে পারসিস্ট
   করে (অ্যাটমিক ডেল্টা অ্যাপেন্ট: ব্লক + টিপ +
   পরিবর্তিত স্টেট — আপসার্ট
   এবং অপসারণ: মেয়াদোত্তীর্ণ ডোমেইন, প্রত্যাহৃত
   TLD)। তাই একটি পুনরায় চালু কখনো মেয়াদোত্তীর্ণ
   রেজিস্ট্রেশন পুনরুত্থিত করতে পারে না;
3. মেমপুল পুনঃসমন্বয় (অন্তর্ভুক্ত tx সরানো
   হয়);
4. পিয়ারদের কাছে সম্প্রচার (প্রেরক
   বাদে)।

একটি অবৈধ ব্লক একটি টাইপড ত্রুটির সাথে
প্রত্যাখ্যাত; রিলে চলতে
থাকে। নেটওয়ার্ক ডেটায় কোনো প্যানিক নয়। ভারী
প্রয়োগ (Argon2 + redb কমিট)
`tokio::task::block_in_place`-এর মধ্য দিয়ে যায় (সিঙ্ক
ড্রাইভার, p2p গ্রহণ, প্রোডাকশন): রানটাইম প্রস্তুত
টাস্কগুলো অন্য
কর্মীদের কাছে সরায় — একটি ব্লক প্রয়োগ আর DNS সেবা
বা
মেট্রিক্স আটকায় না।

### DNS স্ন্যাপশট (পাবলিকেশন)

প্রতিটি প্রয়োগকৃত ব্লকের পরে (p2p গ্রহণ — রিঅর্গসহ —,
সিঙ্ক ড্রাইভার, প্রোডাকশন) এবং বুটে (একটি পুনরায় চালু
অবশ্যই পরবর্তী ব্লক পর্যন্ত লাইভ
নামের NXDOMAIN করবে না), রিলে DNS
পৃষ্ঠ দ্বারা পঠিত `watch` ফিডে **অথরিটেটিভ DNS
স্ন্যাপশট** প্রকাশ করে (সম্পূর্ণ স্পেসিফিকেশন
`dns.md`-এ):

- টিপ এক্সটেনশন (অপ্রতিরোধ্য পাথ): **O(touched)
  ডেল্টা**, কপি-অন-রাইট — ব্লকের লেনদেন স্পর্শকৃত
  ডোমেইনের নাম বহন করে, সাথে ডিটারমিনিস্টিক GC
  অপসারণ (`AppliedBlock.gc_removed_domains`, পুশ
  টাইমে মূল্যায়িত);
- রিঅর্গ / বুট: **সম্পূর্ণ পুনর্নির্মাণ** (একটি পেজড
  `ChainState::dns_facts` ওয়াক)।

### ব্লক প্রোডাকশন (M5: স্বাক্ষরিত প্রোডিউসার)

প্রতি `produce_interval` সেকেন্ডে (ডিফল্টে ২ সে):
মেমপুল অ-খালি হলে, একটি ব্লক `BlockBuilder` দ্বারা
একত্রিত হয় (`timestamp = now`) **একজন অনুমোদিত
প্রোডিউসার দ্বারা স্বাক্ষরিত** (পেলোড
`SCONE-BLOCK-V1` `header.consensus`-এ, দেখুন
`/docs/en/technical/blockchain.md`) এবং ঠিক
একটি গৃহীত ব্লকের গ্রহণের পাথ অনুসরণ করে। tx
ছাড়া একটি রিলে কিছুই
উৎপাদন করে না।

প্রোডাকশন কী: অ্যাঙ্কর কী (`--anchor-key`) যখন রিলে
একটি দিয়ে সজ্জিত থাকে — একজন অ্যাঙ্কর একজন অনুমোদিত
প্রোডিউসার — অন্যথায়
নির্দিষ্ট devnet কী, বৈধ যতক্ষণ প্রোডিউসার পুল
খালি (খোলা বুটস্ট্র্যাপ: জেনেসিস)। যত সাথে সাথে
একটি জীবিত ডোমেইন/TLD থাকে, devnet কী দ্বারা
স্বাক্ষরিত একটি ব্লক প্রত্যাখ্যাত (`InvalidProducer`)।

### অ্যাঙ্কর লুপ (ফাইনালিটি, M5)

`--anchor-key` সহ (`.sconekey` কী-ফাইল, পাসফ্রেজ
`--anchor-passphrase-env` দিয়ে, ডিফল্ট
`SCONE_ANCHOR_PASS` — `scone-network` লাইব্রেরির
ডিফল্ট `SCONE_ANCHOR_PASSPHRASE` বাইনারির মাধ্যমে
কখনো পৌঁছানো যায় না, clap সর্বদা এটি
ওভাররাইড করে):

- **প্রোপোজার ঘূর্ণন**: প্রতি এপোকে ঠিক একজন মনোনীত কমিটি
  সদস্য নিজেই প্রস্তাব করে (`committee[epoch % size]`,
  ডিটারমিনিস্টিক); অন্য সদস্যরা কখনো নিজেদের টিপে স্বাক্ষর
  করে না — একটি চেকপয়েন্টের কনটেন্ট প্রোপোজারের টিপের উপর
  নির্ভর করে, এবং গেটবিহীন স্ব-প্রস্তাবগুলি এপোকটিকে
  প্রতিদ্বন্দ্বী কনটেন্টে ভেঙে দিয়েছিল যা প্রতিটি গার্ড
  সঠিকভাবেই ইকুইভোকেশন হিসেবে প্রত্যাখ্যান করে (টেস্টনেট,
  2026-10-21);
- প্রতিটি গৃহীত/উৎপাদিত ব্লকের পরে, যদি এই নোড
  বর্তমান কমিটির সদস্য হয় **এবং** কমিটি
  `MIN_FINALITY_COMMITTEE_SIZE`-এ
  পৌঁছায়, রিলে তার
  `SignerGuard`-এর মাধ্যমে প্রস্তাবিত
  চেকপয়েন্টে স্বাক্ষর করে (`signer-state.dat`
  data-dir-এ — একটি কী = একটি ভোট/এপোক,
  ক্র্যাশ-সেফ ফেল-ক্লোজড) এবং
  এটি গসিপ করে;
- **vote-on-receipt**: যে প্রস্তাবের কনটেন্ট আমাদের চেইনে বৈধ
  (রেফারেন্সকৃত ব্লকটি উপস্থিত, একই হ্যাশে) এবং একটি কমিটি
  সিগনেচার বহন করে সেটি আমাদের সিগনেচারও পায় — এটি ছাড়া,
  প্রতিটি অ্যাঙ্কর শুধু নিজের টিপের কনটেন্টে স্বাক্ষর করত এবং
  কোরাম কখনোই জমা হত না;
- গৃহীত সিগনেচার (`Message::Checkpoint`)
  `CheckpointData` হ্যাশ দ্বারা জমা হয় (২৫৬টি
  এন্ট্রিতে সীমাবদ্ধ); একই
  ডেটার উপর `quorum_for(কমিটির আকার)` সদস্যের
  সিগনেচারে → `accept_checkpoint` +
  ফাইনালাইজড
  চেকপয়েন্টের সম্প্রচার;
- **ফাইনালিটি পারসিস্টেন্স**: চেকপয়েন্ট উইন্ডো এবং ফ্রোজেন
  বেস প্রতিটি ফাইনালাইজেশনে স্টোরে লেখা হয় এবং বুটে পুনরায়
  লোড হয়। চেকপয়েন্টগুলি GOSSIP স্টেট (কখনোই ব্লক দ্বারা বহিত
  নয়) — এই পারসিস্টেন্স ছাড়া একটি রিস্টার্ট খালি বেস থেকে
  শুরু করত এবং পিয়ার-সরবরাহকৃত উইন্ডো আর কখনো চেইন করতে পারত
  না (নেটওয়ার্কের উইন্ডোর নিচের এপোক অ্যাঙ্করগুলি হারিয়ে
  গেছে);
- **ফাইনালিটি ক্যাচ-আপ**: যে রিলের বেস খালি (একটি নতুন নোডের
  বুট) সে প্রতিটি টিকে একটি পিয়ার থেকে `GetCheckpoints` চায়
  যতক্ষণ না বেস পুনরুদ্ধার হয়;
- অ্যাঙ্কর কী ছাড়া একটি রিলে **নিষ্ক্রিয়**
  থাকে: এটি জমা করে,
  ফাইনালাইজ করে এবং রিলে করে, কিন্তু কখনো
  স্বাক্ষর করে না;
- `GetCheckpoints` → `checkpoint_window()` উইন্ডো
  সেবা পায়;
- যেকোনো লুপ ত্রুটি লগ করা হয় এবং গিলে
  ফেলা হয় — কখনো মারাত্মক নয়;
- স্টেটাস (`GetStatus`) `checkpoints` এবং
  `finalized_epoch` উন্মুক্ত করে।

### ফর্ক পার্কিং এবং রিঅর্গ (sticky-minority সংশোধন)

একই উচ্চতায় একটি বোন ব্লক, বা এমন একটি ব্লক যার
প্যারেন্ট বর্তমান টিপ নয়
(`ParentNotTip`/`UnknownParent`), কখনো হারায়
**না**:
এটি **পার্কড** (বাউন্ডেড ম্যাপ, `PARKED_CAP = 2048` ব্লক,
প্রতিটি ~KiB
— বাউন্ডেড সবচেয়ে খারাপ ক্ষেত্রে RAM; একটি পূর্ণ
পার্কিং নতুনদের নীরবে
উপেক্ষা করে)। `accept_block`-এ ইতিমধ্যে
অফারকৃত হ্যাশ ডিডুপ্লিকেটেড (`seen_blocks`): একটি
পুনঃগসিপকৃত পরাজিত ব্লক পুনঃমূল্যায়িত
হয় না।

প্রতিটি `Produce` টিকে, `reconsider_parked`:

1. পার্কড ব্লকের রৈখিক ড্রেইন যাদের
   প্যারেন্ট টিপ হয়েছে;
2. যদি একটি পার্কড ব্রাঞ্চ বর্তমান টিপের চেয়ে
   শক্তিশালী হয় (ফর্ক-চয়েস
   নিয়ম অপরিবর্তিত: ফাইনালিটি ফ্লোর, দীর্ঘতম
   চেইন, সর্বনিম্ন হ্যাশ), দত্তকগ্রহণ — স্থানচ্যুত
   সাফিক্স নিজেই পার্কড (ফর্কের
   উভয় পক্ষ মূল্যায়নযোগ্য থাকে)।

এটি এমন একটি নোডকে আন-স্টিক করে যেটি
সমান-উচ্চতার ফর্কের পরাজিত পক্ষ
দত্তক নিয়েছে: বিজয়ী ব্লক, একবার অফারকৃত তারপর
প্রত্যাখ্যাত, চিরতরে ভুলে যাওয়ার বদলে
পর্যায়ক্রমে পুনঃমূল্যায়িত হয় (chaos-30
সন্ধান: ১৫ ms আলাদা দুটি বোন ব্লক)।

**রিঅর্গ পারসিস্টেন্স**: অন্য ব্রাঞ্চ দত্তক
নেওয়া একচেটিয়া বর্ধমান অ্যাপেন্টের মধ্য দিয়ে
যেতে পারে না (`NonMonotonicHeight`)। রিলে
`rewind_to_height(ফর্ক পয়েন্ট)` তারপর
`persist_state_snapshot` (চেইনের এক্সপোর্ট থেকে
লাইভ স্টেটের পুনঃলিখন) তারপর বিজয়ী
সাফিক্সের একচেটিয়া বর্ধমান পুনঃঅ্যাপেন্ট প্রয়োগ করে
(`storage.md` দেখুন)। একটি
পারসিস্টেন্স ব্যর্থতা লগ করা হয় এবং অবনমিত (বুটে
রিপ্লের মাধ্যমে সারে) — কখনো মারাত্মক নয়।

`GetBlocks(start = local_height + 1)` চায়। গৃহীত
প্রতিটি `Block` যা ঠিক
প্রত্যাশিত উচ্চতা পূরণ করে পরবর্তী
উচ্চতার অনুরোধ ট্রিগার করে, নিঃশেষ পর্যন্ত

`MAX_SYNC_ROUNDS` (10,000) ব্যাচ — একটি
মিথ্যুক পিয়ারের বিরুদ্ধেও একটি পরম
বাউন্ড। গৃহীত ব্লক সম্পূর্ণ ভ্যালিডেশনের মধ্য দিয়ে
যায়: একটি
ক্ষতিকর পিয়ার কোনো অবৈধ কিছু গ্রহণ
করাতে পারে না।

### রেকর্ড DHT

- **put** (API/web প্রবাহ — CLI হেক্স চ্যানেল
  অপসারিত): কঠোর বাউন্ডেড ডিকোডিং
  (`MAX_DHT_CACHE_ENTRY`), অন-চেইন স্টেটের
  বিরুদ্ধে যাচাই (owner, সিকোয়েন্স, পুনর্গণনাকৃত
  `record_hash` — "রেকর্ড যাচাই" দেখুন), তারপর
  `kad.put_record` (লোকাল স্টোরেজ +
  নিকটতম পিয়ারদের কাছে প্রতিলিপি,
  প্রতিলিপি ফ্যাক্টরের `Quorum::Majority`) এবং
  স্থায়ী redb ক্যাশ।
- **get** (`domain resolve`): `kad.get_record`;
  ওয়েটার তার `QueryId` এবং অনুরোধকৃত
  `DomainId`-র সাথে আবদ্ধ — একটি উত্তর শুধুমাত্র
  মিলমানো কোয়েরি সমাধান করে, এবং রেকর্ড কী
  অবশ্যই ঠিক অনুরোধকৃত ডোমেইন হতে হবে (অন-চেইন
  যাচাইয়ের **আগে** যাচাইকৃত)।
  ফলাফল তারপর ফেরানোর আগে চেইনের
  বিরুদ্ধে যাচাই হয়। একইসাথে
  অনুরোধের ক্যাপ: `MAX_DHT_WAITERS` (256);
  এর বাইরে, তাৎক্ষণিক ত্রুটি। একটি সফলভাবে
  যাচাইকৃত রেজোলিউশন
  স্থায়ী ক্যাশে লেখা হয় (M5): লোকাল
  রিড (`domain_info`) তারপর একটি নতুন DHT
  কোয়েরি ছাড়াই সেবা পায়।
- Kademlia সার্ভার মোডে চলে, কোনো রেকর্ড TTL
  নেই (চেইন
  বৈধতা শাসন করে, সময় নয়)।

### রেকর্ড যাচাই ("চেইনই কর্তৃত্ব" নিয়ম)

একটি রেজোলিউশনকৃত বা গৃহীত `SignedDnsRecord`
শুধুমাত্র তখনই গৃহীত/ফেরানো হয় যদি:

1. ডোমেইন অন-চেইন নিবন্ধিত হয়;
2. `record.owner` = বর্তমান অন-চেইন owner;
3. `record.sequence` = বর্তমান অন-চেইন সিকোয়েন্স;
4. `record_hash(record.record)` (পুনর্গণনাকৃত BLAKE3) =
   অন-চেইনে কমিটেড `record_hash`।

অন্যথায়: P2P দিকে নীরব প্রত্যাখ্যান, CLI দিকে
স্পষ্ট ত্রুটি। রেকর্ডের Ed25519 সিগনেচার রিলে
দ্বারা **গ্রহণে যাচাইকৃত** (`ResolveLocal`): সিগনেচারকে
owner-এর শেখা পাবলিক কী **অথবা** ডোমেইনের
রেকর্ড-ডেলিগেট কীগুলোর যেকোনো একটির বিরুদ্ধে খুলতে
হবে (KSK/ZSK-lite — একজন ডেলিগেট owner-এর হয়ে
প্রকাশ করে; অসম্পর্কিত
কী দ্বারা স্বাক্ষরিত একটি রেকর্ড প্রত্যাখ্যাত,
`record rejected`); এটি ভবিষ্যৎ
ভেরিফায়ারদের জন্যও পরিবহনকৃত — অন-চেইন
কমিটমেন্ট প্রাথমিক
অখণ্ডতা নিয়ন্ত্রণ থাকে।

## Prometheus মেট্রিক্স

একটি HTTP এন্ডপয়েন্ট (Prometheus টেক্সট
ফরম্যাট 0.0.4, হাতে-লেখা
এক্সপোজিশন — কোনো নতুন ডিপেন্ডেন্সি নয়) একটি
নিবেদিত টাস্ক দ্বারা সেবা পায়:

- **ডিফল্টে বন্ধ**: `--metrics-addr` ছাড়া কোনো HTTP সার্ভার চলে না (মেট্রিক্স অপ্ট-ইন)।
- `--metrics-addr ADDR:PORT`: সেই ঠিকানায় এন্ডপয়েন্ট বাঁধে (যেমন লোকাল `127.0.0.1:9101`, বাইরের জন্য `0.0.0.0:9101`)।
- `--metrics-token TOKEN`: **প্রাইভেট**
  মোডে স্যুইচ করে —
  `Authorization: Bearer ***` প্রয়োজন (ধ্রুবক-সময়
  তুলনা, অন্যথায় `401`; টোকেন কখনো লগে
  বা এক্সপোজিশনে দেখা যায় না)।
- একটি বাইন্ড ব্যর্থতা **এন্ডপয়েন্ট
  নিষ্ক্রিয় করে** (অ-মারাত্মক সতর্কতা) —
  কখনো নোড নয়।

কার্যকর বাইন্ড stdout-এ ঘোষণা করা হয়
(মেশিন-পাঠযোগ্য চুক্তি, `p2p:`-এর মতো): একটি
`metrics: <addr>` লাইট যত তাড়াতাড়ি এটি
শোনে।

**১৯টি কাউন্টার** (`counter`, একচেটিয়া বর্ধমান —
হট পাথ: একটি শেয়ার্ড `Arc<Metrics>`-এ
`fetch_add(Relaxed)`, কখনো
কনসেনসাস ইনপুট নয়):

| গ্রুপ | সিরিজ |
|---|---|
| Chain | `scone_blocks_applied_total`, `scone_blocks_rejected_total`, `scone_checkpoints_signed_total`, `scone_checkpoint_sigs_received_total` |
| Mempool | `scone_txs_admitted_total`, `scone_txs_rejected_total`, `scone_txs_evicted_grace_total`, `scone_txs_included_total` |

## CLI নিয়ন্ত্রণ (RPC→p2p একীকরণ)

JSON TCP RPC সার্ভার **অপসারিত** হয়েছে: CLI
(এবং রেজিস্ট্রারের axum ব্রিজ) p2p প্রোটোকল
**সরাসরি** কথা বলে — একই
ওয়্যার (`/scone/reqres/1`), রিলে দিকে একই
হ্যান্ডলার, শূন্য সমান্তরাল চ্যানেল। প্রতিটি
কমান্ড নোডের multiaddr-এ (`--peer`) একটি QUIC
সংযোগ খোলে, একটি `Message` বিনিময় করে, বন্ধ
করে।

রিলে দ্বারা সেবাকৃত নিয়ন্ত্রণ বার্তা:

- `GetStatus` → `NodeStatus { network, nat_reachable,
  tip, height, domain_count, mempool, peers,
  finalized_epoch, checkpoints, fresh_operators }`
  (`scone status` দ্বারা প্রদর্শিত —
  `fresh_operators` = ফ্রেশ হার্টবিটসহ
  অপারেটর, RFC proof-of-service);
- `LookupName { name }` → `NameState`
  (অন-চেইন স্টেট, `lookup`-এর মতো);
- `GetOwnedNames { owner }` → `OwnedNames`
  (একটি `OwnerId`-র লাইভ ডোমেইন + TLD);
- `Transaction (tx)` → ফ্রি গসিপসহ জমা (রিলে
  পিয়ারদের কাছে পুনঃসম্প্রচার করে);
- `GetRecord { domain_id }` / `Record (r)` — DHT
  রেজোলিউশন এবং পাবলিকেশন (CLI দিকে
  `scone domain resolve`-এর মতো);
- প্রয়োগ প্রত্যাখ্যান → `Message::Error(msg)`
  (ক্লায়েন্টের কাছে একটি পাঠযোগ্য বার্তা হিসেবে
  পৌঁছায়, একটি EOF নয়)।

ক্লায়েন্ট একটি ন্যূনতম libp2p স্ওয়ার্ম তোলে
(request-response + identify), ৩০ সে কল
টাইমআউট (২০ সে রাউন্ড ট্রিপ)। ডিফল্ট `--peer`:
`/ip4/127.0.0.1/udp/4001/quic-v1/p2p/12D3KooW…`
(লোকাল dev নোড; প্রকৃত পিয়ার id-সহ সম্পূর্ণ
multiaddr রিলে stdout-এ `p2p:` লাইনের মাধ্যমে
ঘোষণা করে)।

অভ্যন্তরীণ `RelayCommand` চ্যানেল এমবেডেড DNS
পৃষ্ঠের জন্য টিকে থাকে (`ResolveLocal`, একটি
ইন-প্রসেস রাউন্ড ট্রিপ, কখনো একটি DHT
ওয়েটার নয় — `dns.md` দেখুন)।

## CLI

```
scone relay [--network testnet|mainnet|devnet] [--data-dir DIR] [--listen MULTIADDR]
            [--bootstrap MULTIADDR]... [--upnp]
            [--anchor-key PATH] [--no-anchor-auto] [--anchor-passphrase-env VAR] [--genesis FILE]
            [--topology-profile tiny|small|default|high|very-high|devtest]
            [--dns ADDR] [--dns-upstream ADDR]...
            [--metrics-addr ADDR:PORT] [--metrics-token TOKEN]
scone status [--peer MULTIADDR]
scone domains [--identity ID | --pubkey HEX] [--peer MULTIADDR]
scone domain register NAME [--identity ID] [--dir DIR] [--passphrase-env VAR] [--peer MULTIADDR]
scone domain set NAME TYPE VALUE [TTL] [--identity ID] [--peer MULTIADDR]   # express single record
scone domain update NAME --file FILE [--identity ID] [--peer MULTIADDR]
scone domain get NAME [--peer MULTIADDR]
scone domain renew NAME [--identity ID] [--peer MULTIADDR]
scone domain resolve NAME [--peer MULTIADDR]

# --peer defaults to the local relay (SCONE_PEER env overrides);
# --identity defaults to the single keystore identity when there
# is exactly one. Removed (stubs suggest replacements): show,
# submit, lookup, owned.
```

প্রতিটি নিয়ন্ত্রণ কমান্ড রিলের
multiaddr-এ সরাসরি QUIC কথা বলে (`--peer`,
ডিফল্ট লোকাল নোড — RPC→p2p একীকরণ, আর
কোনো JSON TCP চ্যানেল নেই)। রিলে অনুপস্থিত →
স্পষ্ট বার্তা "p2p node unreachable — is a relay
running?", অ-শূন্য প্রস্থান। `--rpc`
ফ্ল্যাগ রাখা হয়েছে কিন্তু **অপ্রচলিত এবং উপেক্ষিত**
(RPC সার্ভার অপসারিত হয়েছে; শুধুমাত্র
স্ক্রিপ্ট সামঞ্জস্য)।

### এনভায়রনমেন্ট কনফিগারেশন (`.env`)

স্টার্টআপে, `scone` (dotenvy-এর মাধ্যমে, clap
পার্সিংয়ের আগে) বর্তমান
ডিরেক্টরি থেকে একটি `.env` ফাইল লোড করে:
অনুপস্থিত ফাইল = নীরব নো-অপ, কখনো ত্রুটি
নয়। লোড করা মানগুলো এমন
অপশনগুলোর **এনভায়রনমেন্টাল বেজলাইন** হয়
যেগুলো একটি ভেরিয়েবল ঘোষণা করে (`cli.rs`-এ
`env = "…"`); **একটি স্পষ্ট CLI ফ্ল্যাগ সর্বদা
`.env`-এর চেয়ে জেতে**, এবং `.env`
বিল্ট-ইন ডিফল্টের চেয়ে জেতে:

```text
explicit CLI flag  >  .env variable  >  built-in default
```

রিপোজিটরি রুটের `.env.example` ফাইল প্রতিটি
ভেরিয়েবল ডকুমেন্ট করে (`.env`-এ
কপি করে সামঞ্জস্য করুন; `.env` **gitignored** —
কখনো একটি প্রকৃত `.env` কমিট করবেন না)। ভেরিয়েবল:

| ভেরিয়েবল | মিরর ফ্ল্যাগ | শব্দার্থ |
|---|---|---|
| `SCONE_NETWORK` | `--network` | `testnet` (ডিফল্ট), `mainnet`, `devnet` |
| `SCONE_DATA_DIR` | `--data-dir` | ডেটা ডিরেক্টরি (ডিফল্ট `~/.scone/<network>/`) |
| `SCONE_LISTEN` | `--listen` | P2P লিসেন multiaddr (ডিফল্ট: সব ইন্টারফেস, এফেমারাল পোর্ট) |
| `SCONE_BOOTSTRAP` | `--bootstrap` | বুটস্ট্র্যাপ সিড, **পুনরাবৃত্তিযোগ্য** (প্রতি মানে একটি লাইন — dotenvy জমা করে); builtin সিড প্রতিস্থাপন করে |
| `SCONE_GENESIS` | `--genesis` | জেনেসিস ফাইল (ফাউন্ডার নোড) |
| `SCONE_MDNS` | `--mdns` | (অপ্রচলিত — mDNS ডিসকভারি সরিয়ে ফেলা হয়েছে; গৃহীত, উপেক্ষিত) |
| `SCONE_UPNP` | `--upnp` | UPnP পোর্ট ম্যাপিং (`true` = সক্ষম) |
| `SCONE_DNS_ADDR` | `--dns` | UDP DNS সার্ভার বাইন্ড ঠিকানা |
| `SCONE_DNS_UPSTREAM` | `--dns-upstream` | রিকার্সিভ ফলব্যাক, **পুনরাবৃত্তিযোগ্য** |
| `SCONE_DNS_CACHE_LIMIT` | `--dns-cache-limit` | DNS ক্যাশ এন্ট্রি ক্যাপ |
| `SCONE_DNS_CACHE_MAX_MEM` | `--dns-cache-max-mem` | DNS ক্যাশ মেমরি ক্যাপ (যেমন `64MB`) |
| `SCONE_DNS_MAX_INFLIGHT` | `--dns-max-inflight` | সমান্তরাল DNS কোয়েরি ক্যাপ |
| `SCONE_METRICS_ADDR` | `--metrics-addr` | metrics endpoint address (`ADDR:PORT`)|
| `SCONE_METRICS_TOKEN` | `--metrics-token` | মেট্রিক্স এন্ডপয়েন্ট বিয়ারার টোকেন |
| `SCONE_TOPOLOGY_PROFILE` | `--topology-profile` | টোপোলজি প্রোফাইল (`tiny`/`small`/`default`/`high`/`very-high`/`devtest`; ডিফল্ট `default`) |
| `SCONE_ANCHOR_KEY` | `--anchor-key` | অ্যাঙ্কর কী-ফাইল (চেকপয়েন্ট + প্রোডাকশন) |

`SCONE_ANCHOR_PASS` কোনো ভেরিয়েবলের
অপশন **নয়**: এটি **অ্যাঙ্কর পাসফ্রেজ ধারণকারী
ভেরিয়েবলের** ডিফল্ট
নাম (`--anchor-passphrase-env`, CLI
স্তরে ডিফল্ট `SCONE_ANCHOR_PASS`) — রিলে
পাসফ্রেজটি সেই
ভেরিয়েবল থেকে পড়ে যার নাম এই
ফ্ল্যাগ দেয়।

**অ্যাঙ্কর অটো (ডিফল্টে ON)**: `--anchor-key`
ছাড়া, একটি অ্যাঙ্কর কী-ফাইল ডেটা
ডিরেক্টরিতে স্বয়ংক্রিয়ভাবে
উৎপন্ন/পারসিস্ট করা হয়
(`anchor.sconekey`, পাসফ্রেজ `SCONE_ANCHOR_PASS`
সংজ্ঞায়িত থাকলে,
অন্যথায় র‍্যান্ডমলি উৎপন্ন এবং `anchor.pass`-এ
লেখা) — রিলে একজন প্রোডিউসার হয়ে ওঠে যত সাথে
সাথে তার কী লাইভ
ডোমেইন/TLD-র মালিক হয় (PoS এলিজিবিলিটি কখনো
বিনামূল্যে নয়)। `--no-anchor-auto`
রিলেকে কঠোরভাবে নিষ্ক্রিয় রাখে। `--anchor-passphrase-env`-এর
ডিফল্ট env ভ্যারিয়েব্ল `SCONE_ANCHOR_PASS`।

`--network`: ডিফল্ট BUILD অনুসরণ করে
(মেইননেট-সক্ষম বাইনারিতে mainnet, অন্যথায়
testnet); `devnet` হলো
রিসেটযোগ্য লোকাল নেটওয়ার্ক (নিজের
`scone-devnet` জেনেসিস, প্রায়-শূন্য 0..=2 বিট
PoW — `~/.scone/devnet/` মুছে
রিলে পুনঃলঞ্চ করলে চেইন রিসেট হয়)। জেনেসিস,
PoW ডিফিকাল্টি এবং ডিফল্ট
data-dir (`~/.scone/<network>/`) সেট করে; অন্য
নেটওয়ার্কের একটি tx টাইপডভাবে
প্রত্যাখ্যাত (`WrongNetwork`)।

অফলাইন হেক্স সারফেস (`tx` এবং `submit`
সাবকমান্ড) চলে গেছে (remove-tx-surface-v2)। CLI
ব্যবহারকারীর পাথ
(`domain register`, `domain renew`, `domains`) এবং
M8b
পরিবারকে ফার্স্ট-ক্লাস কমান্ড হিসেবে কভার করে:
`tld open`, `tld transfer`, `tld revoke`, `domain
assign`, `domain transfer`।
`register` ক্লেইম নেটওয়ার্ক
ডিফিকাল্টিতে তাদের PoW মাইন করে
(devnet-এ মিলিসেকেন্ড)।

**কোনো geo বা হেলথ অপশন নেই**: geozone
**build-কর্তৃক-আরোপিত** (এমবেডেড DB-IP Lite টেবিল — সম্পূর্ণ
শব্দার্থ
[`dns.md`](dns.md#geodns-geographic-routing)-এ); ভৌগোলিক
রাউটিং কোনো অপশন ছাড়াই **সর্বদা চালু**, এবং রিজলভার কোনো
হেলথ চেকিং করে না — এটি স্বাক্ষরিত রেকর্ড সেটটিকে যেমন আছে
তেমনই সরবরাহ করে (endpoint-এর প্রাপ্যতা endpoint অপারেটরদের
ব্যাপার)। যেকোনো `--geo-*`/`--health-*` ফ্ল্যাগ একটি কঠোর
clap প্রত্যাখ্যান।

### `domain register|update` (M5) — এক কমান্ডে স্বাক্ষরিত লেনদেন

এই কমান্ডগুলো একটি একক আহ্বানে চেইন
বিল্ড → স্বাক্ষর (keystore) → জমা →
(নিশ্চয়তা) করে।

- **register**: একটি স্বাক্ষরিত `RegisterDomain`
  তৈরি করে (টাইমস্ট্যাম্প = now, devnet-এ
  খালি প্রুফ), জমা দেয়, অন-চেইন
  নিশ্চয়তার অপেক্ষা করে (sequence ≥ 0, ৩০ সে
  টাইমআউট)। ইতিমধ্যে নিবন্ধিত
  একটি নাম ক্লায়েন্ট-দিকে এবং
  রিলে-দিকে প্রত্যাখ্যাত।
- **update**: রেকর্ড ফাইলই একমাত্র সত্যের
  উৎস। সিকোয়েন্স (অন-চেইন + 1) এবং
  `record_hash` (ফাইলের রেকর্ডের
  ক্যানোনিকাল BLAKE3) **ডেরিভড**, কখনো
  প্রবেশ করানো হয় না: স্বাক্ষরকারী এবং
  ভেরিফায়াররা বিভক্ত হতে পারে না।
  UpdateDomain নিশ্চয়তার পরে,
  `SignedDnsRecord` (ফাইলের রেকর্ড + owner +
  ক্যানোনিকাল এনকোডিংয়ের উপর Ed25519
  সিগনেচার) `put_record`-এর মাধ্যমে DHT-তে
  প্রকাশিত হয় (যা চেইনের বিরুদ্ধে
  পুনঃযাচাই করে)। একটি
  অনিবন্ধিত ডোমেইন, একটি অ-owner
  পরিচয়, বা একটি ফাইল ত্রুটি পরিষ্কারভাবে
  ব্যর্থ হয়, চেইন স্পর্শ না
  করে।

#### রেকর্ড ফাইল

টেক্সট, প্রতি লাইনে একটি রেকর্ড, `#` =
কমেন্ট, খালি লাইন উপেক্ষিত; সাজানো
ক্যানোনিকাল এনকোডিং ফাইলের ক্রমকে
কমিটেড হ্যাশের উপর কোনো প্রভাব ফেলতে
বাধ্য করে না। ফাইলটি সম্পূর্ণ
সেট (একটি আপডেট প্রতিস্থাপন করে, একত্রিত করে
না)। টাইপ:

```text
A 192.0.2.1
AAAA 2001:db8::1
CNAME www.example.uip
NS ns1.example.uip
MX 10 mail.example.uip
TXT free text (spaces normalized)
```

টাইপড ত্রুটি: অজানা ধরন, অবৈধ IP/নাম (লাইন
নম্বরসহ), খালি সেট, ডুপ্লিকেট,
> `MAX_RECORDS_PER_SET`।

## `--genesis` (ফাউন্ডার)

`scone relay --genesis genesis.bin` — **শুধুমাত্র
ফাউন্ডার নোড**
(কিকস্টার্টার প্রচারণা; ফাইলটি `scone-genesis`
বাইনারি দ্বারা উৎপাদিত)। নরমেটিভ নিয়ম:

1. ফাইলটি 1 MiB ছাড়িয়ে গেলে **পড়ার
   আগেই** প্রত্যাখ্যাত, তারপর কঠোরভাবে ডিকোড
   হয় (`decode_complete`: কোনো ট্রেইলিং
   বাইট নেই)। ব্লক ০-এর হ্যাশ
   **পুনর্গণনাকৃত**, কখনো ফাইল থেকে
   পড়া হয় না।
2. শব্দার্থিক ভ্যালিডেশন: উচ্চতা 0,
   `consensus` অনুরোধকৃত নেটওয়ার্কের
   নেটওয়ার্ক id (`--network`) দিয়ে শুরু,
   কোনো লেনদেন নেই,
   ক্যানোনিকাল অ্যালোকেশন ম্যানিফেস্ট।
   যেকোনো লঙ্ঘন = স্টার্টআপে টাইপড ত্রুটি
   (কখনো প্যানিক নয়, ডেমন চালু হয় না)।
3. **ভার্জিন** data-dir: চেইন অ্যালোকেটেড
   জেনেসিসে জন্মায় — অ্যালোকেশন
   যেকোনো ডিস্ক রাইটের **আগে** RAM-এ
   প্রয়োগ হয়, তারপর
   পারসিস্ট করা হয় (সিডেড স্টেট +
   মেটা কী-এর অধীনে জেনেসিস ব্লক)।
   তাই প্রথম
   উৎপাদিত ব্লক শুধুমাত্র অ্যালোকেটেড
   জেনেসিস সম্প্রসারিত করতে
   পারে।
4. **ইতিমধ্যে প্রোডাক্টিভ** data-dir:
   স্টোরের জন্ম জেনেসিস
   ব্লক ১-এর `prev_hash` (স্ব-শংসাপত্র)। সমান
   ফাইল হ্যাশ = নীরব OK (অপশনটি
   **প্রথম স্টার্টআপের পরে রিডান্ডেন্ট**);
   ভিন্ন = টাইপড প্রত্যাখ্যান — একটি
   নোড sync-এর মাধ্যমে
   নেটওয়ার্কে যোগ দেয়, কখনো
   `--genesis`-এর মাধ্যমে নয়।
5. অপশন **ছাড়া** পুনরায় চালু:
   ফাউন্ডার-জন্মা data-dir মেটা কী-এর
   মাধ্যমে তার অ্যালোকেটেড
   জেনেসিস পুনরুদ্ধার করে (প্রতিটি
   বুটে RAM রিবাইন্ড)।

ধ্রুবক জেনেসিস হ্যাশ পিন (অ্যান্টি
নেটওয়ার্ক-বিভাজন) একটি
পৃথক ওয়ার্কস্ট্রিম।

### `scone-genesis` বাইনারি ম্যানিফেস্ট (কিকস্টার্টার)

`scone-genesis` বাইনারি (ক্রেট
`scone-genesis`) `genesis-manifest.json` ম্যানিফেস্ট
(`ALLOC-V1` ফরম্যাট) প্রস্তুত করে তারপর
`genesis.bin` উৎপাদন করে। নরমেটিভ নিয়ম:

- `scone-genesis new --network <network>` একটি খালি
  ম্যানিফেস্ট তৈরি করে; `add`/`remove`/`list`
  অ্যালোকেশন পরিচালনা করে, `build`
  `genesis.bin` উৎপাদন করে (+ হ্যাশ), `verify`
  এটি পুনঃভ্যালিডেট করে।
- `add domain <name>` চায় ডোমেইনের
  **TLD ইতিমধ্যে ম্যানিফেস্টে অ্যালোকেটেড
  হয়ে থাকে** (অন্যথায় তাৎক্ষণিক প্রত্যাখ্যান —
  চেইন এটি জেনেসিস প্রয়োগে
  প্রত্যাখ্যান করত); এর
  `valid_until` **স্বয়ংক্রিয়**: `born_at + 1 year`
  (ম্যানিফেস্টের default_validity), কখনো
  হাতে প্রবেশ করানো হয় না।
- `add tld <name>`: **ডিফল্টে ওপেন**
  (কারো নয়, স্ব-সেবা,
  ১-বছর ফ্লোর, ওয়্যারে owner = শূন্য —
  kind `0x03`); `--private` = প্রাইভেট (owner,
  জেনেসিস মেয়াদ `born_at + TLD_TERM_SECS` — ৩
  বছর, স্ট্যান্ডার্ড জীবনচক্র: `RenewTld`,
  ৬০-দিনের গ্রেস)।
- নাম অনুযায়ী ক্যানোনিকাল সাজানো (সমান
  কনটেন্ট → একই ব্লক → একই
  হ্যাশ, সন্নিবেশ ক্রম যাই হোক না
  কেন); ডুপ্লিকেট প্রত্যাখ্যাত।

## সীমা এবং মেমরি নিশ্চয়তা

| রিসোর্স | বাউন্ড |
|---|---|
| P2P ফ্রেম | পার্সিংয়ের আগে `MAX_MESSAGE_LEN` (1 MiB) |
| মেমপুল | 4096 tx (বাইরে টাইপড প্রত্যাখ্যান); প্রতি ডোমেইনে `MAX_PENDING_PER_DOMAIN = 4` বিচলিত tx |
| মেমপুল গ্রেস | `MAX_GRACE_ATTEMPTS = 10` একটি tx-এর পুনঃসন্নিবেশ যা একটি অ-চূড়ান্ত কারণে ফ্লাশ হয়েছে (৪০ সে/চক্রে ≈ ৭ মিনিট), তারপর বহিষ্করণ |
| ফর্ক পার্কিং | `PARKED_CAP = 2048` প্রতিযোগী ব্লক |
| জমাকৃত চেকপয়েন্ট | `MAX_PENDING_CHECKPOINTS = 256` (বহিষ্করণ: ক্ষুদ্রতম ডেটা হ্যাশ) |
| একইসাথে DHT ওয়েটার | `MAX_DHT_WAITERS` (256); DHT লুকআপ 30 সে-তে সীমাবদ্ধ (`DHT_LOOKUP_TIMEOUT`) |
| প্রতি সিঙ্ক উত্তরে ব্লক | প্রতি রাউন্ড-ট্রিপে ১টি; প্রতি পিয়ারে ≤ 10,000 ব্যাচ (`MAX_SYNC_ROUNDS`); অনুরোধে প্রোটোকল বাউন্ড `MAX_BLOCKS_PER_REQUEST = 128` |
| DHT রেকর্ড | `MAX_DHT_CACHE_ENTRY` (64 KiB) |
| স্থায়ী DHT ক্যাশ (ডিস্ক) | দ্বৈত LRU বাউন্ড: `DHT_CACHE_MAX_ENTRIES` (১০০,০০০ এন্ট্রি) এবং `DHT_CACHE_MAX_BYTES` (2 GiB) — যেটি আগে লাগে সেটি কী ক্রমে বহিষ্কার করে; ব্লকের একই লেনদেনে GC বহিষ্করণ (চেইন GC দ্বারা নিহত একটি ডোমেইন কখনো একটি এতিম এন্ট্রি রেখে যায় না) |
| DHT নেগেটিভ ক্যাশ | `DHT_NEGATIVE_TTL_SECS` (30 s), FIFO ক্যাপ `DHT_NEGATIVE_CAP` (4,096) |
| RAM-এ চেইন | জেনেসিস + টিপ উইন্ডো (ইতিহাস স্টোর থেকে সেবা পায়) |

অ্যান্টি-লুপ নিয়ম (H2): একটি লেনদেন শুধুমাত্র
তখনই পুনঃসম্প্রচারিত হয় যদি এটি মেমপুলে
**প্রকৃতপক্ষে সন্নিবেশিত** হয় (প্রথম দর্শন); একটি
ডুপ্লিকেট (ইতিমধ্যে পুলে বা ইতিমধ্যে চেইনে)
কখনো পুনঃরিলে হয় না।
একটি ইতিমধ্যে-ক্যানোনিকাল ব্লক
`push_block`-এর আগে সনাক্ত এবং উপেক্ষিত
হয় (কোনো পুনঃস্টোর নেই, কোনো পুনঃসম্প্রচার
নেই)।

খোলা সিদ্ধান্ত: রিলের স্থায়ী নেটওয়ার্ক পরিচয়,
ব্রডকাস্ট
গসিপ (বর্তমানে: প্রতিটি পরিচিত পিয়ারে
ইউনিকাস্ট request-response)।
প্রাথমিক লেখা থেকে সমাধানকৃত: প্রকৃত
ফর্ক চয়েস (পার্কিং + reconsider_parked, উপরে
দেখুন), PoW কনসেনসাস (স্বাক্ষরিত প্রোডিউসার +
অ্যাঙ্কর কমিটি), DNS রিজলভার (`--dns` পৃষ্ঠ,
dns.md দেখুন), নিয়ন্ত্রণ চ্যানেল (RPC→p2p
একীকরণ: আর কোনো JSON
TCP নেই)।

## গ্রেসফুল শাটডাউন (SIGTERM / SIGINT)

`scone relay` ডেমন (ফোরগ্রাউন্ড)
`tokio::signal`-এর মাধ্যমে SIGTERM এবং SIGINT
ধরে: সংকেতে, `Relay::run` ফিউচার
বাতিল হয় (বাইনারিতে `tokio::select!`), যা libp2p
স্ওয়ার্ম ড্রপ করে এবং QUIC সকেট
বন্ধ করে। tokio রানটাইম তারপর
একটি বাউন্ডেড শাটডাউন (≤ ২ সে) দিয়ে
থামানো হয় যা বিচ্ছিন্ন
DNS টাস্ক (UDP/TCP) ড্রপ করে এবং তাদের
সকেট বন্ধ করে — লক্ষ্য হলো একটি
`kill` কোনো এতিম UDP সকেট রেখে যায় না
(টেস্টনেট 60-এ পর্যবেক্ষিত ক্ষেত্রে)।
একটি সংকেত-চালিত শাটডাউন `relay shutting down
(signal)` লগ করে (INFO, stderr) এবং
প্রস্থান কোড **0** দিয়ে প্রস্থান করে: একটি
অনুরোধকৃত শাটডাউন ব্যর্থতা
নয়। হ্যান্ডলার ইনস্টলেশন ব্যর্থ হলে,
সংকেতের ডিফল্ট
আচরণ প্রযোজ্য (অবনমন, কখনো প্যানিক
নয়)।


## Tor ট্রান্সপোর্ট (খোলা সমস্যা)

QUIC/UDP সরল SOCKS প্রক্সি অতিক্রম করে
না, তাই রিলেরা আজ Tor-এর উপরে
তুচ্ছভাবে চলতে পারে না। একটি নেটিভ libp2p Tor
ট্রান্সপোর্ট (onion-ঠিকানাযুক্ত রিলে) সামনের
ট্র্যাককৃত পথ — ওয়েবসাইটের সেন্সরশিপ-প্রতিরোধ
গাইড দেখুন বর্তমান অবস্থা এবং
`.tor` CNAME ব্রিজের (হিডেন সার্ভিসের
জন্য পাঠযোগ্য নাম,
আজ সমর্থিত) জন্য।
