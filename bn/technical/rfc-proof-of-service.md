# RFC — অপারেশন প্রুফ ও ফাইনালিটি কমিটি (proof-of-service)

> অবস্থা: নরমেটিভ — শুরু থেকে শেষ পর্যন্ত ইমপ্লিমেন্টেড (ধাপ ১ থেকে ৫:
> core/protocol/blockchain/network/CLI; এই ডকুমেন্ট হলো
> সমন্বিত রূপ)। নিচের প্রতিটি নিয়ম কোডের বিরুদ্ধে যাচাইকৃত;
> উদ্ধৃত ধ্রুবকগুলো কোডেড মান।
> তারিখ: অক্টোবর ২০২৬ (নরমেটিভ সমন্বয়)। স্পর্শ করে:
> `scone-core`, `scone-protocol`, `scone-blockchain`,
> `scone-network`, `scone` (CLI)।

## ১. প্রেরণা

ফাইনালিটি পুল হলো owner পুল (লাইভ ডোমেইন/TLD-র owner-গুলো)।
মালিকানা একটি সিট দেয় — **অপারেশন** কিছু দেয় না। এই RFC
চেকপয়েন্ট স্বাক্ষরের অধিকারকে একটি অনলাইন
রিলের অপারেশন প্রুফের সাথে বাঁধে, কখনো মালিকানাকে শর্তাবদ্ধ না
করে:

- **সংরক্ষিত স্বাধীনতা**: একটি প্রাইভেট TLD তার মেয়াদ নবায়ন থাকা
  পর্যন্ত কোনো কার্যকলাপ শর্ত ছাড়াই অ্যাসাইনযোগ্য থাকে
  (`RenewTld`, ৩-বছর মেয়াদ)। শুধুমাত্র *চেকপয়েন্ট স্বাক্ষর* উপস্থিতির
  মাধ্যমে অর্জিত।
- **অপারেট করার প্রণোদনা**: একটি প্রাইভেট TLD (বা যেকোনো সিট)
  অপারেট করা = কমিটিতে বসা। অপারেটর নেটওয়ার্ক
  চালু রাখার অংশ নেয় এবং প্রোটোকল এটি স্বীকার করে।
- **পরিমাপযোগ্য বিকেন্দ্রীকরণ**: কমিটি হয়ে ওঠে *প্রকৃতপক্ষে
  অনলাইন* অপারেটরদের সেট, নিদ্রিত কী নয়।

## ২. ওভারভিউ

একটি হালকা `Heartbeat` লেনদেন (ডিসক্রিমিন্যান্ট `0x71`),
একটি **অপারেটর** কী দ্বারা স্বাক্ষরিত, প্রতি এপোকে একবার নির্গত।
স্টেট সাম্প্রতিক হার্টবিটের একটি স্লাইডিং উইন্ডো ধারণ করে।
একটি এপোকের কমিটি পুলের সেই সাবসেট থেকে নির্বাচিত হয় **যার
কার্যকর অপারেটরের একটি ফ্রেশ হার্টবিট আছে**। হার্টবিট ছাড়া:
স্বাক্ষর নেই, কিন্তু মালিকানার অধিকার হারায় না।

## ৩. Heartbeat লেনদেন

```
Heartbeat {
    operator: PublicKey,     // Ed25519 key of the operator (the signer)
    owner: OwnerId,          // identity RE-DERIVED from operator (never trusted)
    tip_seen: [u8; 32],      // last tip seen by the node
    height_seen: u64,        // corresponding height
    timestamp: u64,          // Unix seconds
} + Ed25519 signature over the canonical payload (network injected)
```

স্বাক্ষরিত বডি (ওয়্যার, `scone-protocol`):
`operator[32] ‖ owner[32] ‖ tip_seen[32] ‖ height_seen.v ‖
timestamp.v ‖ operator[32]` (স্বাক্ষরকারীর কী বডির শেষে
আসে, প্রতিটি tx-র মতো) `‖ signature[64]`, অর্থাৎ ~২৩০ বাইট
এনকোডেড — **কোনো PoW নেই**: খরচ হলো একটানা উপস্থিতি (প্রতি
এপোকে একটি হার্টবিট, মাসের পর মাস)।

স্বাক্ষরকারীই অপারেটর: `owner` সর্বদা `operator` থেকে
পুনঃডেরিভড (কখনো ইনপুট থেকে নেওয়া হয় না), এবং ডিকোডিং হেড
`operator` ফিল্ড থেকে ভিন্ন একটি সিগনেচার কীকে টাইপড ত্রুটির
(`InvalidOwner`) সাথে প্রত্যাখ্যান করে।

- `tip_seen`/`height_seen` পর্যবেক্ষণযোগ্যতা সেবা করে (বাগি
  বা পিছিয়ে থাকা অপারেটরের সনাক্তকরণ); এগুলো বৈধতাকে প্রভাবিত
  করে **না** (হালকাভাবে পিছিয়ে থাকা একটি নোড এখনও একটি লাইভ
  নোড)।

### 3.1 বিশুদ্ধ ভ্যালিডেশন (scone-core)

1. নেটওয়ার্কের ক্যানোনিকাল পেলোডের উপর বৈধ Ed25519 সিগনেচার।
2. `owner` == `operator` থেকে ডেরিভড পরিচয় (অন্যথায়
   `InvalidOwner`) — এনকোডে, ডিকোডে AND `validate()` দ্বারা যাচাইকৃত।

### 3.2 স্টেট নিয়ম (প্রয়োগ, scone-blockchain)

উচ্চতা `block_height`-এর একটি বহনকারী ব্লকে একটি হার্টবিট
প্রয়োগের সময় (প্রতিটি প্রত্যাখ্যান যেকোনো মিউটেশনের আগে):

1. **ক্রস-এপোক অ্যান্টি-রিপ্লে**: প্রতি অপারেটরে `timestamp`
   কঠোরভাবে বর্ধমান — `timestamp <= operator_last_hb[operator]`
   হলে টাইপড প্রত্যাখ্যান `StaleHeartbeat`।
2. **প্রতি-এপোক অনন্যতা**: প্রতি (`operator`, বহনকারী ব্লকের
   এপোক)-এ শুধুমাত্র একটি হার্টবিট গৃহীত — ডুপ্লিকেট টাইপড
   ত্রুটির (`HeartbeatDuplicate`) সাথে প্রত্যাখ্যাত। এপোক হলো
   `block_height / epoch_min_blocks` (ফাইনালিটির মতোই সংজ্ঞা,
   কখনো নতুন ধ্রুবক নয়)।
3. উইন্ডোতে জার্নালড সন্নিবেশ + `operator_last_hb` আপডেট
   (রিঅর্গে প্রত্যাবর্তনযোগ্য, বিট-সঠিক আন্ডো)।

### 3.3 অ্যান্টি-স্প্যাম

- প্রতি অপারেটরে প্রতি এপোকে ১টি গৃহীত tx — সর্বোচ্চ প্রবাহ
  `pool_size / epoch_secs`, নগণ্য।
- কোনো ফি নেই (প্রি-ইকোনমি): হার কাঠামোগতভাবে সীমাবদ্ধ।

## ৪. অপারেশন ডেলিগেশন

সিট → অপারেটর সংযোগ দুটি নিবেদিত লেনদেনের মধ্য দিয়ে যায়:

- `SetTldOperator { tld_id, operator }` (ডিসক্রিমিন্যান্ট `0xA9`),
  **প্রাইভেট** TLD-র **বর্তমান** owner দ্বারা স্বাক্ষরিত (একটি ওপেন
  TLD-র বৈধভাবে স্বাক্ষর করার কেউ নেই — টাইপড প্রত্যাখ্যান
  `TldIsOpen`)। `operator: None` = প্রত্যাহার, owner-এর কী দিয়ে
  স্ব-অপারেশনে ফেরত; তাৎক্ষণিকভাবে প্রত্যাহারযোগ্য।
- `SetDomainOperator { domain_id, operator }` (ডিসক্রিমিন্যান্ট
  `0x5E`), ডোমেইনের বর্তমান owner দ্বারা স্বাক্ষরিত। একই
  শব্দার্থ।
- `RegisterTld` / `RegisterDomain` / `AssignDomain` কোনো
  `operator` ফিল্ড বহন করে **না**: সিট → অপারেটর সংযোগ সর্বদা
  টিপে সমাধানকৃত একটি সাম্প্রতিক অন-চেইন তথ্য।

ওয়্যারে অপারেটর অপশন ক্যানোনিকাল: `0x00` = `None`
(স্ব-অপারেশন), `0x01` = কাঁচা ৩২-বাইট কী; অন্য যেকোনো মান
ডিকোডে প্রত্যাখ্যাত।

স্টেট বজায় রাখে:

```
seat_operators: HashMap<OwnerId, OperatorKey>   // per seat
operator_seats: HashMap<OperatorKey, u64>       // bounded counter
operator_last_hb: HashMap<OperatorKey, u64>     // last accepted ts
```

প্রয়োগ নিয়ম (`apply_seat_operator`, জার্নালড):

- **ইডেম্পোটেন্স**: একই অপারেটরে পুনঃডেলিগেশন (বা
  অস্তিত্বহীন ডেলিগেশন প্রত্যাহার) একটি অ-জার্নালড নো-অপ
  (বিট-সঠিক আন্ডো এটি চায়)।
- **অ্যান্টি-রেন্টাল বাউন্ড**: একটি অপারেটরকে একই সময়ে শুধুমাত্র
  **একটি একক সিট** দ্বারা ডেলিগেট করা যায়
  (`MAX_SEATS_PER_OPERATOR = 1`)। ইতিমধ্যে নেওয়া একটি
  অপারেটরে দ্বিতীয় সিট ডেলিগেট করলে → টাইপড
  প্রত্যাখ্যান `OperatorAlreadyDelegated`। যুক্তি: বাউন্ড
  ছাড়া একটি বড় অপারেটর বাল্কে স্বাক্ষর বিক্রি করে এবং কেন্দ্রীকরণ
  পুনরায় তৈরি করে — ঠিক যা নির্বাচিত কমিটি এড়াতে
  চায়।

## ৫. ফ্রেশনেস উইন্ডো

### 5.1 স্লাইডিং উইন্ডো

```
recent_heartbeats: BTreeMap<(epoch, OperatorKey), ()>
```

- একটি বৈধ হার্টবিট প্রয়োগের সময় এন্ট্রি সন্নিবেশিত (§3.2)।
- প্রতিটি ব্লক প্রয়োগে ডিটারমিনিস্টিক পার্জ
  (`gc_heartbeats_journaled`): এপোক `e`-এর যেকোনো এন্ট্রি
  `e + HEARTBEAT_WINDOW_EPOCHS <= epoch` হলে সরানো হয় (জার্নালড —
  রিঅর্গে প্রত্যাবর্তনযোগ্য, মেয়াদ সারির মতো)।
- `HEARTBEAT_WINDOW_EPOCHS = 2`: বর্তমান এপোক + পূর্ববর্তী
  এটি — একজন অপারেটর একটি এপোক মিস করলেও ফ্রেশনেস হারায় না,
  দ্বিতীয়টি মেয়াদোত্তীর্ণ করে।
- **কাঠামোগত মেমরি ক্যাপ**: উইন্ডো সর্বাধিক
  `HEARTBEAT_WINDOW_EPOCHS × operator_count` এন্ট্রি ধরে (প্রতি
  অপারেটরে প্রতি এপোকে একটি, টাপল কী); `operator_last_hb`
  অপারেটর সংখ্যা দ্বারা সীমাবদ্ধ এবং কখনো পার্জ হয় না (অ্যান্টি-রিপ্লে
  নিয়ম একচেটিয়া বর্ধমান)।

### 5.2 ফ্রেশনেস

"ফ্রেশ" = `[epoch − HEARTBEAT_WINDOW_EPOCHS + 1, epoch]`-এর
`e`-এর জন্য একটি `(e, operator)` এন্ট্রির উপস্থিতি। যেহেতু স্টেট
প্রতিটি ব্লকে পার্জ করে, `recent_heartbeats`-এ উপস্থিতিই
ফ্রেশনেস (`operator_is_fresh`)।

### 5.3 কার্যকর অপারেটর

একটি সিটের **কার্যকর অপারেটর** হলো একটি লাইভ
ডেলিগেশন থাকলে `seat_operators[seat]`, অন্যথায় owner-এর কী
(`effective_operator`)। সিট সেই কার্যকর কী-এর অধীনে স্বাক্ষর করে —
একটি ডেলিগেশন স্বাক্ষরের অধিকার সরায়, মালিকানা কখনো নয়।

## ৬. কমিটি নির্বাচন

```
eligible = { effective operators of the frozen pool's seats
             (banned key excluded) having a fresh heartbeat }

if |eligible| >= MIN_FINALITY_COMMITTEE_SIZE (= 4) :
    committee = select_committee(seed, eligible)   // existing draw
else :
    committee = select_committee(seed, pool)       // safe degradation
```

নরমেটিভ বিবরণ (`finality.rs`-এ যাচাইকৃত, নির্দিষ্ট
`/docs/en/technical/blockchain.md` § "Seats and the finality
committee"-এ):

- `pool` হলো **শেষ ফাইনালাইজড চেকপয়েন্টে ফ্রোজেন** পুল
  (`FinalizedBase.pool` — কখনো লাইভ স্টেট নয়): একটি
  লোকাল ভিউ নোডের মধ্যে বিভক্ত হতো এবং কোরাম কখনো
  গঠিত হতো না;
- `seed` পূর্ববর্তী চেকপয়েন্টের কনটেন্ট হ্যাশ
  (`signing_hash`) থেকে ডেরিভ হয়;
- ফ্রোজেন পুলের প্রতিটি সিট টিপের স্টেট দ্বারা তার কার্যকর
  অপারেটরে সমাধান হয় (ডেলিগেশন ও হার্টবিট
  সাম্প্রতিক অন-চেইন তথ্য: একই টিপের দুটি নোড একই
  সেট গণনা করে); নিষিদ্ধ কী বাদ থাকে;
- ড্র কার্যকর কীগুলোর সাজানো/ডিডুপ্লিকেটেড সেটের উপর চলে
  (`select_committee` অপরিবর্তিত)।

**স্পষ্ট ও নিরাপদ অবক্ষয়**: একটি বুটস্ট্র্যাপিং নেটওয়ার্ক (কোনো
হার্টবিট নেই), বা অপারেটরদের সাধারণ বিভ্রাট, সম্পূর্ণ
পুলে ফিরে যায় — গঠনগতভাবে ফাইনালিটি কখনো হারায় না। এটিই
এই প্রকল্পের "কখনো ডেডলক নয়" নিয়ম এখানে প্রয়োগকৃত।

### 6.1 কোল্ড বুটস্ট্র্যাপ

এপোক ০ (এবং যতক্ষণ `MIN_FINALITY_COMMITTEE_SIZE`-এর কম
অপারেটর ফ্রেশ): সম্পূর্ণ পুল। অপারেটররা নির্গত করার সাথে সাথে
শর্তটি স্বাভাবিকভাবে কঠোর হয়। কনফিগার করার কোনো বিশেষ
পরিবর্তনকালীন সময় নেই।

## ৭. স্বয়ংক্রিয় নির্গমন (scone-network)

প্রতিটি প্রোডাকশন চক্রে (`Wake::Produce` — কোনো নতুন টাইমার নয়),
রিলে যাচাই করে একটি এপোক সীমানা অতিক্রান্ত হয়েছে কিনা
(`height / epoch_min_blocks`, ফাইনালিটির মতোই সংজ্ঞা)। একটি
নতুন এপোকের প্রথম চক্রে, এটি একটি হার্টবিট নির্গত করে যদি:

1. একটি অ্যাঙ্কর কী সজ্জিত থাকে (`--anchor-key` বা অটো), AND
2. সেই কী নিজেই একটি লাইভ সিট ধারণ করে (লোকাল যাচাই: কীটি
   অন-চেইন এলিজিবিলিটি পুলে আছে — লাইভ ডোমেইন/TLD-র owner-গুলো,
   নিষিদ্ধ কী বাদ)।

লোকাল অ্যান্টি-স্প্যাম: প্রতি নোডে প্রতি এপোকে সর্বাধিক একটি নির্গমন
(`last_emitted_epoch` মেমো, লোকাল মেমরি, কখনো চেইন স্টেট নয়);
মেমো শুধুমাত্র একটি সফল মেমপুল ইনজেকশনের পরে নেওয়া হয় — একটি
ব্যর্থতা পরবর্তী চক্রে পুনঃচেষ্টা করে। এখানে কিছুই মারাত্মক নয়:
সবচেয়ে খারাপে হার্টবিট পরবর্তী চক্রের অপেক্ষা করে।

একজন **ডেলিগেটেড অপারেটর** (যিনি নিজে owner নন) স্বয়ংক্রিয়
নির্গমন দ্বারা কভারড নন: তারা §৮-এর CLI বিল্ডারের মাধ্যমে নির্গত
করেন (ম্যানুয়াল বা এয়ার-গ্যাপড অপারেশন)। হার্টবিট প্রয়োজনীয়ভাবে
নির্গমনকারী নিজের দ্বারা একটি ব্লকে উৎপাদিত হয় **না**: এটি
অন্য যেকোনো tx-এর মতো (মেমপুল, যে কারো দ্বারা প্রোডাকশন)।

## ৮. CLI (`scone`)

অফলাইন হার্টবিট বিল্ডার (`tx` সারফেসের সাথে অপসারিত) অফলাইন tx
সারফেসের সাথে অপসারিত হয়েছে (cli-simplify-v1)। রিলেরা
নিজেরাই স্বয়ংক্রিয়ভাবে হার্টবিট নির্গত করে (§৭); ম্যানুয়াল/এয়ার-গ্যাপড
নির্গমন, যদি কখনো আবার প্রয়োজন হয়, একটি নিবেদিত
কমান্ড হিসেবে ফিরে আসবে। ডিফল্ট ছিল: `tip_seen` = ৩২টি শূন্য বাইট
(শুধুই পর্যবেক্ষণযোগ্যতা), `height_seen` = 0, `timestamp` = now।
- প্রতিটি tx-র মতো, `tx sign` অপারেটর ও owner-কে প্রকৃত
  সাইনিং কী-তে **পুনঃবাঁধে** (ইনপুট মান কখনো বিশ্বাস করা হয় না); `tx verify`
  লোকালি ভ্যালিডেট করে।

## ৯. পর্যবেক্ষণযোগ্যতা

- `NodeStatus` (ওয়্যার p2p বার্তা `0x0d`) বহন করে
  `fresh_operators: u32` (ভ্যারিন্ট): ফ্রেশ হার্টবিটসহ অপারেটরদের
  সংখ্যা — কমিটির জন্য এলিজিবল পুলের লাইভ সাবসেট (পুলের সিটের
  কার্যকর অপারেটর, নিষিদ্ধ কী বাদ, সাজানো/ডিডুপ্লিকেটেড)। রিলে
  `state().fresh_operators(height)` থেকে পূরণ করে; `scone status`
  `fresh operators: N` হিসেবে প্রদর্শন করে।
- প্রচারণা যুক্তি: "একটি প্রাইভেট TLD অপারেট করা = বিকেন্দ্রীকৃত
  DNS-এর ফাইনালিটি কমিটিতে বসা" — অন-চেইনে
  যাচাইযোগ্য।
- ভবিষ্যৎ পৃষ্ঠ (অনির্দিষ্ট): `operator_status` — প্রতি সিটে,
  ডেলিগেটেড অপারেটর, ফ্রেশনেস (ফ্রেশ / মেয়াদোত্তীর্ণ / কখনো দেখা
  যায়নি), শেষ `tip_seen`। লোকাল কন্ট্রোল RPC অপসারিত হয়েছে
  (শুধুমাত্র-p2p নোড); পৃষ্ঠটি এখনও সংজ্ঞায়িত হতে হবে।

## ১০. এই RFC যা করে না

- নিষ্ক্রিয়তার জন্য **কোনো দখল হানি নেই** (বিকল্প A — অ-অপারেটেড
  TLD-র ক্ষয় — স্পষ্টভাবে প্রত্যাখ্যাত)।
- **কোনো পুরস্কার নেই** (বিকল্প C একটি অর্থনৈতিক স্তরের অপেক্ষায়)।
- হার্টবিট সেবার *গুণমান* প্রমাণ করে না (উৎপাদিত ব্লক,
  সেবাদত্ত DHT রেকর্ড) — শুধুমাত্র উপস্থিতি। প্রকৃত
  অবদান গণনা একটি সম্ভাব্য ভবিষ্যৎ সম্প্রসারণ, আরও গেমযোগ্য।

## ১১. সুরক্ষিত অপরিবর্তনীয় সত্য

- বিট-সঠিক ডিটারমিনিজম: উইন্ডো ও নির্বাচন প্রয়োগকৃত
  স্টেটের বিশুদ্ধ ফাংশন (জার্নালড, বিট-সঠিক আন্ডো)।
- নেটওয়ার্ক ডেটায় কখনো প্যানিক নয়: বিকৃত হার্টবিট বা ডেলিগেশন
  → টাইপড প্রত্যাখ্যান (`InvalidOwner`, `StaleHeartbeat`,
  `HeartbeatDuplicate`, `OperatorAlreadyDelegated`, `TldIsOpen`,
  `NotTldOwner`, `NotOwner`)।
- দখল শর্তহীন; শুধুমাত্র চেকপয়েন্ট স্বাক্ষর
  শর্তাধীন।
