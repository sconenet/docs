# सकोन दस्तावेज़ीकरण

> `docs/` के अंतर्गत सारा दस्तावेज़ीकरण **नॉर्मेटिव (मानक-निर्धारक)** है: इसे Rust
> पढ़े बिना एक स्वतंत्र कार्यान्वयन संभव बनाना चाहिए। दस्तावेज़/कोड में
> कोई भी विचलन एक बग है (सत्य का स्रोत पहचानें, उसे ठीक करें)।

दो भाग:

- **`general/`** — यह कैसे काम करता है: प्रोटोकॉल की अवधारणाएँ और नियम,
  बिना प्रारूपों के विवरण पढ़े सुलभ;
- **`technical/`** — डेवलपर्स के लिए विस्तृत विनिर्देश: सटीक
  बाइनरी प्रारूप, हैश सूत्र, सीमाएँ, API, और
  प्रत्येक घटक का व्यवहार।

## `general/` — यह कैसे काम करता है

| दस्तावेज़ | सामग्री |
|---|---|
| [architecture.md](general/architecture.md) | प्राधिकार (ब्लॉकचेन) / उपलब्धता (DHT) / स्थानीय भंडारण का पृथक्करण; crates की भूमिकाएँ; DNS रिज़ॉल्यूशन प्रवाह; विकसनीयता |
| [naming.md](general/naming.md) | नामकरण नियम: LDH वर्णमाला, TLD, डोमेन और सबडोमेन, कैननिकलकरण, `DomainId` व्युत्पत्ति और हेक्साडेसिमल प्रतिनिधित्व |
