# Документация Scone

> Вся документация в `docs/` является **НОРМАТИВНОЙ**: она должна
> позволить независимую реализацию без чтения Rust-кода. Любое
> расхождение между документацией и кодом — это баг (нужно определить
> источник истины и исправить его).

Две части:

- **`general/`** — как это устроено: концепции и правила протокола,
  доступные без чтения деталей форматов;
- **`technical/`** — подробные спецификации для разработчиков: точные
  двоичные форматы, формулы хеширования, границы, API и поведение
  каждого компонента.

## `general/` — как это устроено

| Документ | Содержание |

| [architecture.md](general/architecture.md) | Разделение полномочий (блокчейн) / доступности (DHT) / локального хранилища; роли крейтов; поток разрешения DNS; эволюционность |
